# מצגת 3ה: חקירות שדה: SPT, מכנף גזירה ו-CPT

> ⚡ **בקצרה:** בודקים את הקרקע **בשטח, בעומק**. הבדיקה הנפוצה בארץ: **SPT**: סופרים **הקשות פטיש** שמחדירות דוגם. התוצאה **N** = ההקשות ב-**30 הס"מ האחרונים**.

---

## 🔨 SPT: בדיקת החדרה תקנית

- **S**tandard **P**enetration **T**est. **הבדיקה המקובלת בארץ.**
- רעיון: כמו לתקוע **מסמר בקיר**. קיר קשה → צריך **יותר מכות**.

**המספרים:**

- משקולת **64 ק"ג**
- נופלת מגובה **75 ס"מ**
- מחדירים דוגם **45 ס"מ** = 3 קטעים של **15 ס"מ**

```
     [====]   hammer 64 kg
       ||     drops 75 cm, again and again
 ======||=======  ground
       ||     borehole + rod
       ||
      |  |    0-15 cm  -> NOT counted
      |  |   15-30 cm  -> counted
      |  |   30-45 cm  -> counted
      \__/    sampler

   N = blows (15-30) + blows (30-45)
```

**השלבים:**

1. קודחים **בור** עד העומק הרצוי.
2. מחדירים את הדוגם **45 ס"מ** בהפלות המשקולת.
3. סופרים הקשות לכל **15 ס"מ**.
4. **N** = סכום ההקשות ב-**30 הס"מ האחרונים**. את **15 הראשונים לא סופרים**.

**דוגמה:** רישום **5-6-6**

1. 5 = ה-15 ס"מ הראשונים → **לא נספר**
2. N = 6 + 6 = **12**
3. בדיקה: 3 מספרים = 3 קטעים × 15 ס"מ = 45 ס"מ ✓

**מתי עוצרים?**

- קרקע **קשה מאוד**: קטע אחד של 15 ס"מ דורש **מעל 50 הקשות** → **מפסיקים**.
- יצאו בסך הכול **מעל 100 הקשות** → רושמים כשבר, למשל **100/45**.

## 🌀 מכנף גזירה (Vane)

- מכשיר עם **4 להבים** על **מוט פלדה** קשיח.

```
  top view (from above):

         |
     ----+----   <- 4 blades on a steel rod
         |

  turn the rod -> blades cut the soil -> measure torque
```

1. מחדירים את המכשיר לעומק הבדיקה.
2. **מסובבים** → הלהבים **גוזרים** את הקרקע.
3. מודדים את **מומנט הפיתול** הדרוש לסיבוב.
4. ממנו מחשבים את **החוזק לגזירה** של הקרקע.

## 📍 בדיקת CPT

- מחדירים **מוט** לקרקע **בקצב קבוע** (דחיפה, לא הקשות).
- מודדים 2 דברים:
  1. **התנגדות להחדרה**: בקצה (בבסיס הדוגם).
  2. **התנגדות לגזירה**: לאורך **המעטפת** של הדוגם.
- **CPTU** = אותו דבר, ומודד **גם** את **לחץ מי הקבובים** (מי תהום).

## 📊 השוואה מהירה

| בדיקה | איך | מה מקבלים |
|---|---|---|
| **SPT** | **הקשות** פטיש | **N** = מספר הקשות |
| **מכנף גזירה** | **סיבוב** להבים | **חוזק גזירה** |
| **CPT / CPTU** | **דחיפה** בקצב קבוע | התנגדות **בקצה** + **במעטפת** (+ לחץ מים) |

## 🧠 לזכור

- SPT: **64 ק"ג**, **75 ס"מ**, **45 ס"מ**. N = **30 הס"מ האחרונים**.
- **מעל 50** הקשות ל-15 ס"מ → עוצרים.
- מכנף = **מומנט** → חוזק גזירה. CPT = **דחיפה רציפה**.
