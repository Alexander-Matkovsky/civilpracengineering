# מצגת 5 · חלק 2/4: רטיבות, גבולות הסומך ומיון AASHTO

> ⚡ **בקצרה:** כמות ה**מים** בקרקע (**ω**) קובעת אם היא **מוצקה**, **פלסטית** או **נוזלית**. לפי הניפוי והרטיבות **ממיינים** את הקרקע בשיטת **AASHTO** (A-1 עד A-7).

---

## 🏰 הרעיון

- ארמון חול: חול **יבש** → מתפורר.
- חול **לח** → מחזיק צורה.
- **הרבה** מים → הארמון **נוזל**.
- אותה קרקע, כמות מים אחרת → התנהגות אחרת.

## 💧 תכולת רטיבות ω (אומגה)

**ω = Mw ÷ Ms × 100**  [%]

- **Mw** = משקל ה**מים** בדגימה [g]
- **Ms** = משקל ה**מוצקים**: הקרקע היבשה, אחרי ייבוש [g]

**דוגמה:** דגימה רטובה **120 g**. אחרי ייבוש: **100 g**.

1. Mw = 120 − 100 = **20 g**
2. Ms = **100 g**
3. ω = 20 ÷ 100 × 100 = **20%**
4. ✔️ בדיקה: מחלקים ב**יבש** (100), לא ברטוב (120).

> ⚠️ טעות נפוצה: 20 ÷ 120 ≈ 17%. זה **לא נכון**.

**למה זה חשוב?** ω מספר מה יקרה לקרקע במגע עם מים:

1. כמה טוב אפשר **להדק** אותה
2. **תפיחה**
3. **מעבר מים** דרכה
4. **חוזק**

## 📏 גבולות הסומך

```
 dry ------------------------------------------> wet   (w)
       SOLID      |     PLASTIC      |    LIQUID
                  PL                 LL
                  |<------ PI ------>|
```

- **PL** = גבול הפלסטיות (ωP): מעבר מ**מוצק** ל**פלסטי** (כמו פלסטלינה).
- **LL** = גבול הנזילות (ωL): מעבר מ**פלסטי** ל**נוזלי**.
- **PI** = אינדקס הפלסטיות: כמה מים אפשר להוסיף **בתחום הפלסטי** לפני שהקרקע נוזלת.

**PI = LL − PL**  [%]

- PI **גדול** → הקרקע **סופגת** הרבה מים → **תופחת ומתכווצת** יותר. רע לכביש.

**דוגמה:** LL = **45%**, PL = **25%**, ובשטח ω = **30%**.

1. PI = 45 − 25 = **20%**
2. ω = 30% נמצא בין 25 ל-45 → מצב **פלסטי**.
3. ✔️ בדיקה: 25 < 30 < 45.

### איך מודדים?

- **PL**: מגלגלים "**נקניק**" מהקרקע. ב-PL כבר אי אפשר לגלגל אותו לעובי **3 מ"מ**: הוא נשבר לחתיכות של בערך **1 ס"מ**.
- **LL**: חורצים **חריץ** תקני בקרקע, במכשיר תקני. ב-LL החריץ **נסגר אחרי 25 הקשות**.

## 🗂️ מיון AASHTO

- **למה ממיינים?** כדי לדעת מראש את **אופי** הקרקע, ואיזה **מצע** צריך לעבודה.
- **על מה המיון מבוסס?** (1) **ניפוי** ודירוג. (2) **רטיבות** במצבים שונים: ממוצק לבוצי.

| סוג | בקיצור |
|---|---|
| **A-1** | חצץ, חול ושברי אבן, **מדורג היטב** (כמו מצע) |
| **A-2** | חומר **גרנולרי**, חול חרסיתי כמו **חמרה** |
| **A-3** | חול **דק** (דיונות, ים), **בלי** דקים |
| **A-4** | קרקע **טינית**, לא פלסטית או פלסטית **מעט** |
| **A-5** | כמו A-4, אבל **LL גבוה** יותר |
| **A-6** | **חרסית פלסטית**, בדרך כלל מעל **75%** עובר #200 |
| **A-7-6** | חרסיות עם LL **גבוה** מ-A-6 |
| **A-7-5** | חרסיות, כולל **חוואר מופר** |

- טריק: **מספר נמוך** = קרקע **גרגרית**, טובה לכביש. **מספר גבוה** = יותר **חרסית**.
- ℹ️ בשקף כתוב "A-6-7" ו-"A-5-7". השמות המקובלים: **A-7-6** ו-**A-7-5**.

## 🧠 לזכור

- **ω = מים ÷ יבש** × 100.
- מוצק → **PL** → פלסטי → **LL** → נוזלי. **PI = LL − PL**.
- AASHTO: **A-1** גרגרי וטוב, **A-7** חרסית.
