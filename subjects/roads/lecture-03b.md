# מצגת 3ב: מיון קרקעות: גודל גרגר וניפוי

> ⚡ **בקצרה:** **שיטת המיון האחידה** נותנת לכל קרקע **אותיות** (G, S, M, C, O). קודם בודקים **גודל גרגר** עם **נפות**. נפה **#4 (4.75 מ"מ)** מפרידה בין חצץ לחול. נפה **#200 (0.075 מ"מ)** מפרידה בין **גסים** ל**דקים**.

---

## 🔤 5 האותיות

| אות | באנגלית | בעברית |
|---|---|---|
| **G** | Gravel | **חצץ** (צרורות) |
| **S** | Sand | **חול** |
| **M** | Silt | **טין** |
| **C** | Clay | **חרסית** |
| **O** | Organic | **אורגנית** |

## 📏 גודל הגרגר קובע את הסוג

```
  bigger <------------ grain size (mm) ------------> smaller

    GRAVEL     |     SAND     |   SILT (M)   |    CLAY
 --------------+--------------+--------------+-----------
             4.75           0.075          0.005
            sieve #4      sieve #200
  <------ COARSE (G, S) ----->|<------ FINES (M, C) ----->
```

- **מעל 4.75 מ"מ** → חצץ
- **0.075 עד 4.75 מ"מ** → חול
- **0.005 עד 0.075 מ"מ** → טין
- **מתחת ל-0.005 מ"מ** → חרסית

## 🔍 איך בודקים כל קבוצה?

- **גסים** (חצץ, חול) → **ניפוי בנפות** → **דירוג** (הפתק הזה).
- **דקים** (טין, חרסית) → בדיקות ב**תכולות רטיבות שונות** (פתק 3ד).

## 🧺 ניפוי (אנליזה מכנית)

דוגמה מהחיים: **מסננת קמח**. הגדול נשאר למעלה, הקטן עובר.

1. שוקלים מדגם (בשקף: **6,610 גר'**).
2. מעבירים דרך **ערימת נפות**: הגדולה למעלה, הקטנה למטה.
3. שוקלים כמה **נשאר על כל נפה**.
4. מחשבים לכל נפה:
   - **% נשאר** = משקל על הנפה ÷ משקל כולל × 100
   - **שיור מצטבר** = סכום ה-% מהנפה הגדולה ועד הנפה הזאת
   - **% עובר** = 100 − שיור מצטבר

**דוגמה: נפה #4 בטבלה מהשקף**

1. נשאר: 790 ÷ 6,610 × 100 ≈ **12%**
2. שיור מצטבר: 58% (מהנפות שמעליה) + 12% = **70%**
3. עובר: 100 − 70 = **30%** ✓ (כמו בטבלה)

- **70%** נשאר מעל 4.75 מ"מ → רוב המדגם **חצץ**.
- רק **4%** עובר נפה #200 → מעט מאוד **דקים**.

## 📈 עקום דירוג

- ציר X: **גודל גרגר** [מ"מ] בסקאלה **לוגריתמית** (0.01, 0.1, 1, 10, 100).
- ציר Y: **% עובר**. (בצד ימין: שיור מצטבר.)
- **מדורג היטב (W)** = יש **הרבה גדלים** שונים → עקום **שטוח ופרוש**.
- **מדורג רע (P)** = כמעט **גודל אחד**, או **חסרים** גדלים → עקום **תלול** או עם **קפיצה**.

```
 A: many sizes                B: almost one size
 % pass                       % pass
 100 |          __            100 |       _
     |       _-'                  |      |
     |    _-'                     |      |
     | _-'                        |      |
   0 +-----------> mm (log)     0 +------'-----> mm (log)
     flat, spread = W             steep = P
```

- **% עובר = 100 − שיור מצטבר**.
