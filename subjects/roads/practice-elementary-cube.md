# תרגול 3 · הקוביה האלמנטרית

> ⚡ **בקצרה:** קרקע = **מוצק + מים + אוויר**. מציירים קובייה: **נפחים משמאל**, **משקלים מימין**, ומשלימים את החסר.

---

## 🧽 הרעיון

- כמו **ספוג**: יש חומר (מוצק), ובחורים יש **מים** ו**אוויר**.
- **משקל האוויר = 0**.
- **מים:** 1 ליטר שוקל **1 ק"ג** → **γw = 1** (g/cm³ = kg/L = t/m³).

## 🧊 הקובייה

```
   VOLUME              WEIGHT
             +---------+
   Va        |   AIR   |   Wa = 0
             +---------+
   Vw        |  WATER  |   Ww
             +---------+
   Vs        |  SOLID  |   Ws
             +---------+
   Vt = Vs + Vw + Va       Wt = Ws + Ww
   Vv = Vw + Va  (voids)
```

## 🧮 הנוסחאות

| סימן | שם | נוסחה |
|---|---|---|
| **ω** | תכולת רטיבות | Ww / Ws |
| **γt** | משקל מרחבי כולל | (Ws + Ww) / Vt |
| **γd** | משקל מרחבי יבש | Ws / Vt |
| **n** | נקבוביות | Vv / Vt |
| **e** | מנת חללים | Vv / Vs |
| **S** | דרגת רוויה | Vw / Vv |
| **Gs** | משקל יחסי של מוצקים | Ws / (Vs · γw) |

- **קיצור שימושי:** **γd = γt / (1 + ω)**
- ω מחלקים ב-**Ws** (לא ב-Wt).
- n מחלקים ב-**Vt**. e מחלקים ב-**Vs**.

## 🍳 מתכון

1. לצייר את הקובייה. לסמן **נתון** ו**חסר (?)**.
2. להתחיל מ**צד המשקלים** (שם יש רק נעלם אחד): **Ww = Wt − Ws**
3. נפח המים: **Vw = Ww / γw** (מספרית: אותו מספר).
4. נפח האוויר: **Va = Vt − Vs − Vw**
5. רק עכשיו: להציב בנוסחאות.
6. **בדיקה:** n ו-S בין **0 ל-1**. γd **קטן** מ-γt.

## 🧪 דוגמה פתורה

נתון: Vt = **1000 cm³**, Wt = **1800 g**, Ws = **1500 g**, Vs = **550 cm³**.

1. Ww = 1800 − 1500 = **300 g**
2. Vw = 300 / 1 = **300 cm³**
3. Va = 1000 − 550 − 300 = **150 cm³**
4. ω = 300 / 1500 = **20%**
5. γt = 1800 / 1000 = **1.8 g/cm³**
6. γd = 1500 / 1000 = **1.5 g/cm³**
7. n = (300 + 150) / 1000 = **45%**
8. e = 450 / 550 ≈ **0.82**
9. S = 300 / 450 ≈ **67%**
10. בדיקה: γt / (1 + ω) = 1.8 / 1.2 = **1.5** = γd ✓

## 🧺 סוג שאלה שני: דלי + דגימה

נתון: משקל קרקע בדלי, נפח הדלי, ודגימה קטנה **לפני ואחרי ייבוש**.

1. מהדגימה: **ω = (רטוב − יבש) / יבש**
2. מהדלי: **γt = משקל / נפח**
3. **γd = γt / (1 + ω)**

## ⚠️ טעויות נפוצות

- ω = Ww / **Wt** ✗ → נכון: Ww / **Ws**.
- לבלבל **n** (חלקי Vt) עם **e** (חלקי Vs).
- לשכוח ש**לאוויר יש נפח**, אבל **אין משקל**.
- לערבב **g** עם **kg**, או **cm³** עם **ליטר**.

## 🧠 לזכור

- **3 פאזות**: מוצק, מים, אוויר. לאוויר אין משקל.
- להתחיל מ**המשקלים**. ואז Vw = Ww.
- **γd = γt / (1 + ω)**
