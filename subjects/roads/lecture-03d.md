# מצגת 3ד: קרקעות דקות: גבולות אטרברג ו-AASHTO

> ⚡ **בקצרה:** **דקים** = מה ש**עובר נפה #200 (0.075 מ"מ)**. ממיינים אותם לפי **גבולות אטרברג** (גבולות הסומך): **PL** (מוצק → פלסטי), **LL** (פלסטי → נוזלי), ו-**PI = LL − PL**.

---

## 🍪 הרעיון: פלסטלינה

- **מעט מים** → הקרקע **מתפוררת** (מצב **מוצק**).
- **עוד מים** → אפשר **לעצב** אותה כמו פלסטלינה (מצב **פלסטי**).
- **הרבה מים** → **בוץ** שזורם (מצב **נוזלי**).
- גבולות אטרברג = **תכולות הרטיבות** שבהן הקרקע **עוברת ממצב למצב**.

```
 low  <------------- water content w -------------->  high
 +----------------+------------------+------------------+
 |     SOLID      |     PLASTIC      |      LIQUID      |
 +----------------+------------------+------------------+
                  ^                  ^
               PL (wP)            LL (wL)
            plastic limit       liquid limit
                  |<------ PI ------>|
```

## 1️⃣ גבול הפלסטיות: PL (ωP)

- ה-ω שבה הקרקע עוברת מ**מוצק** ל**פלסטי**.
- **הבדיקה:** מגלגלים "**נקניק**" מהקרקע.
  - ב-PL כבר **אי אפשר** לגלגל נקניק דק מ-**3 מ"מ** בלי שיישבר.
  - הוא נשבר לחתיכות של בערך **1 ס"מ**.

## 2️⃣ גבול הנזילות: LL (ωL)

- ה-ω שבה הקרקע עוברת מ**פלסטי** ל**נוזלי**.
- **הבדיקה:** חורצים **חריץ סטנדרטי** בקרקע, במכשיר סטנדרטי, ונותנים הקשות.
  - ב-LL החריץ **נסגר** אחרי **25 הקשות**.

## 3️⃣ אינדקס הפלסטיות: PI

**PI = LL − PL** (ב-%, כמו ω)

- = כמה מים אפשר **להוסיף** לקרקע בתחום הפלסטי, לפני שהיא הופכת **לנוזלית**.
- **PI גדול** → הקרקע **סופגת הרבה מים** → יותר **תפיחה** ו**התכווצות** → בעייתית לכביש.

**דוגמה:** LL = 45%, PL = 20%

1. PI = 45 − 20 = **25%**
2. בדיקה: PL קטן מ-LL, ולכן PI **חיובי** ✓

## 🔤 האות השנייה: L / H

- **L** = Low plasticity → פלסטיות **נמוכה**
- **H** = High plasticity → פלסטיות **גבוהה**
- הסמל = **סוג + תכונה**. למשל **CL** = חרסית בפלסטיות נמוכה, **MH** = טין בפלסטיות גבוהה.
- (רשות, לא בשקף: בשיטה האחידה **LL < 50% → L**, ו-**LL ≥ 50% → H**.)

## 🛣️ מיון בשיטת AASHTO

| קבוצה | איזו קרקע |
|---|---|
| **A-1** | תערובת **מדורגת היטב** של צרורות, חול ושברי אבן (**מצע**) |
| **A-2** | חומר **גרנולרי**, חול חרסיתי (למשל **חמרה**) |
| **A-3** | חול **דיונות** דק או חול **ים**, בלי דקים |
| **A-4** | קרקע **טינית**, לא פלסטית או בפלסטיות **נמוכה** |
| **A-5** | כמו A-4, אבל **LL גבוה** יותר |
| **A-6** | **חרסית פלסטית**, בדרך כלל **מעל 75%** עובר #200 |
| **A-7-6** | חרסיות עם **LL גבוה** יותר מ-A-6 |
| **A-7-5** | חרסיות. גם **חוואר מופר** נכלל כאן |

- כלל אצבע (רשות): **A-1** הכי טובה מתחת לכביש. ככל שהמספר **עולה**, הקרקע **פחות** טובה.

> ⚠️ בשקף כתוב "A-6-7" ו-"A-5-7". כנראה הסדר התהפך בהקלדה מימין לשמאל. השם המקובל: **A-7-6** ו-**A-7-5**.

## 🧠 לזכור

- **PL**: מוצק → פלסטי (נקניק **3 מ"מ**). **LL**: פלסטי → נוזלי (**25 הקשות**).
- **PI = LL − PL**. PI גדול = **תפיחה**.
- **L / H** = פלסטיות נמוכה / גבוהה.
