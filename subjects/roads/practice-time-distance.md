# תרגול 10 · תרשים דרך-זמן

> ⚡ **בקצרה:** כל צוות = **קו** (ק"מ מול ימים). הצוות הבא מתחיל כך שבכל נקודה בדרך יש **לפחות 2 ימים** רווח מהצוות שלפניו.

---

## 🚧 הרעיון

- בפרויקט ארוך (כביש, מדרכה) הצוותים עובדים **בטור**, אחד אחרי השני.
- צוות מהיר **לא יכול לעקוף** צוות איטי.
- הדרישה בדף: **מרווח של יומיים לפחות** בין צוות לצוות, **בכל נקודה**.

## 🧮 נוסחאות

- **משך פעילות: t = אורך / הספק** (km ÷ km ליום)
- בתרשים: **קו תלול** = צוות **איטי**. קו שטוח = צוות מהיר.

## 📏 חוק המרווח

| הצוות הבא… | איפה הרווח הכי קטן? | הכלל |
|---|---|---|
| **איטי** יותר | ב**התחלה** | התחלה = התחלת הקודם **+ 2** |
| **מהיר** יותר | ב**סוף** | סיום = סיום הקודם **+ 2**, ואז התחלה = סיום − משך |

- ההספק **משתנה בדרך** (חול ואז סלע)? → לבדוק את הרווח בכל **נקודת שבירה**.

## 🍳 מתכון

1. לחשב **משך** לכל פעילות.
2. פעילות 1 מתחילה ביום **0**.
3. כל פעילות הבאה: **איטית** או **מהירה** מהקודמת? → לפי החוק.
4. לרשום **התחלה** ו**סיום** בטבלה.
5. לשרטט: **ק"מ** בציר X, **ימים** בציר Y. קו לכל פעילות.
6. **משך הפרויקט** = סיום הפעילות **האחרונה**.
7. **גאנט:** פס אופקי לכל פעילות, מהתחלה עד סיום.
8. **בדיקה:** בהתחלה ובסוף, הפער בין כל שני קווים סמוכים ≥ 2?

## 🧪 דוגמה פתורה

כביש **3 km**. פעילות A: **1 km/יום**. B: **0.5 km/יום**. C: **1.5 km/יום**.

1. משכים: A = **3**, B = **6**, C = **2** ימים.
2. A: יום **0 → 3**.
3. B **איטי** מ-A → התחלה = 0 + 2 = **2** → סיום **8**.
4. C **מהיר** מ-B → סיום = 8 + 2 = **10** → התחלה = 10 − 2 = **8**.
5. משך הפרויקט = **10 ימים**.
6. בדיקה: ב-km 0: A=0, B=2, C=8 ✓. ב-km 3: A=3, B=8, C=10 ✓.

```
 day
  10 |               C
   9 |       C
   8 |C              B
   7 |            B
   6 |          B
   5 |       B
   4 |     B
   3 |  B            A
   2 |B         A
   1 |     A
   0 |A
     +----------------
      0    1    2    3   km

   A = crew 1 (fast)   B = crew 2 (slow, steep)   C = crew 3 (fast)
```

## 📝 סוגי שאלות בדפים

- **מדרכה** (4 פעילויות): משך מינימלי + **גאנט**.
- **כביש בין שני יישובים**, עם קטע **חול** וקטע **סלע**:
  - מאיזה צד **להתחיל**? (לבדוק את שני הכיוונים, לבחור את הקצר)
  - **שני צוותי עפר במקביל**, מכל צד: איך זה משנה את המשך?
  - **איחוד** שתי פעילויות להספק אחד: כדאי? (להשוות משכים)
  - מעבר בין סוגי קרקע: העבודה בקרקע החדשה מתחילה **רק ביום שאחרי**.
- ההמשך (עלויות ותזרים) → [פתק 11](practice-cash-flow.md).

## ⚠️ טעויות נפוצות

- לבדוק רווח רק **בהתחלה** גם כשהבא **מהיר** (ואז הוא "נתקע" בקודם בסוף).
- להפוך את המשך: הספק / אורך ✗ → נכון: **אורך / הספק**.
- לשכוח את **יום המעבר** בין חול לסלע.
- לשכוח שה**כיוון** שבו מתחילים משנה את התוצאה.

## 🧠 לזכור

- **t = אורך / הספק**
- הבא **איטי** → +2 **בהתחלה**. הבא **מהיר** → +2 **בסוף**.
- משך הפרויקט = **סיום האחרון**.
