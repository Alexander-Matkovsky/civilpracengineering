# מצגת 4ג: סוגי מכבשים

> ⚡ **בקצרה:** בוחרים מכבש לפי **סוג הקרקע**: **ויברציוני** לגסים, **רגלי כבש** לחרסית פלסטית, **פנאומטי** לאספלט. מהדקים בשכבות של **עד 20 ס"מ**.

---

## 🛞 4 סוגי הידוק

1. **מכבש ויברציוני** (רוטט)
2. **מכבש פנאומטי** (גלגלי גומי)
3. **מכבש רגלי כבש**
4. **הידוק דינמי** (רק מוזכר בשקף, בלי פירוט)

## 1️⃣ ויברציוני

- מתאים ל**כל** סוגי הקרקע.
- **הכי יעיל**: קרקע **גסה** (חצץ, חול) **בלי דקים**.
- מתאים גם להידוק ב-**ω גבוהה** מה-ω האופטימלית שנמצאה **במעבדה**.
- קיים ב**כמה משקלים**: מכבש גדול עם תוף, מכבש קטן עם 2 תופים, ומהדק **ידני** קטן.

## 2️⃣ פנאומטי

- **הרבה גלגלי גומי**. אפשר **לשלוט בלחץ** בגלגלים.
- בעיקר ב**סלילת אספלט**, כדי לקבל משטח מוגמר **חלק**.

## 3️⃣ רגלי כבש

- ל**קרקעות דקות** עם **פלסטיות גבוהה** (חרסית).
- ה"**רגליים**" הבולטות מהתוף → **לחץ מגע גבוה** בקרקע.
- יוצר **חיבור וערבוב** טוב בין **שכבות** ההידוק.

## 🧭 איך בוחרים?

```
 SOIL                                ROLLER
 coarse (gravel, sand), no fines ->  VIBRATORY
 fine, high plasticity (clay)    ->  SHEEPSFOOT
 asphalt, smooth final surface   ->  PNEUMATIC (rubber tires)
```

- את סוג ההידוק והמכבש בוחרים לפי **המלצת מהנדס הקרקע**.

## 📏 שכבות

```
  =========  layer 3  (max 20 cm)  <- compact
  =========  layer 2  (max 20 cm)  <- compact
  =========  layer 1  (max 20 cm)  <- compact
  ~~~~~~~~~  ground below
```

- נהוג להדק בשכבות של **עד 20 ס"מ**.
- כל שכבה מהדקים **לפני** שמניחים את הבאה.

## 🧠 לזכור

- גסים → **ויברציוני**. דקים פלסטיים → **רגלי כבש**. אספלט → **פנאומטי**.
- שכבות **≤ 20 ס"מ**.
- הבחירה לפי **מהנדס הקרקע**.
