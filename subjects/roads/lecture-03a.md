# מצגת 3א: הקובייה האלמנטרית

> ⚡ **בקצרה:** כל קרקע = **מוצק + מים + אוויר**. מציירים אותם כ**קובייה** של 3 שכבות ומחשבים **יחסים** ביניהן. הכי חשובים: **ω** (רטיבות) ו-**γd** (משקל מרחבי יבש).

---

## 🎯 למה זה חשוב?

- בכבישים ובפיתוח, רוב העבודה = **עבודות עפר**: חפירה, מילוי, הבאת קרקע ו**מצע**.
- כדי לעבוד נכון צריך **להכיר את הקרקע** → **בדיקות אתר ומעבדה** → **מיון** הקרקע.

## 🧊 הרעיון: 3 פאזות

- **מוצק** (הגרגרים), **מים**, **אוויר**.
- דוגמה מהחיים: **צנצנת חצץ**. האבנים = מוצק. שופכים קצת מים = מים. מה שנשאר ריק = אוויר.
- "מפרידים" אותם בדמיון לשכבות. לכל שכבה יש **נפח V** ו**משקל W**.

```
   Volume (V)                 Weight (W)
               +-----------+
   Va          |    AIR    |   Wa = 0
               +-----------+
   Vw          |   WATER   |   Ww
               +-----------+
   Vs          |   SOLID   |   Ws
               +-----------+
   Vt = Vs + Vw + Va          Wt = Ws + Ww
   Vv = Vw + Va  (voids = water + air)
```

- **t** = כולל, **s** = מוצק, **w** = מים, **a** = אוויר, **v** = **חללים**.
- **משקל האוויר = 0**.

## 🧮 4 יחסים בלי יחידות

| סמל | שם | נוסחה | טווח |
|---|---|---|---|
| **ω** (אומגה) | **תכולת רטיבות** | **ω = Ww / Ws** | 0 < ω < ∞ |
| **n** | **נקבוביות** | **n = Vv / Vt** | 0 < n < 1 |
| **e** | **מנת חללים** | **e = Vv / Vs** | 0 < e < ∞ |
| **S** | **דרגת רוויה** | **S = Vw / Vv** | 0 ≤ S ≤ 1 |

- **S = 1** → כל החללים מלאים במים → **רווי**.
- **S = 0** → אין מים → **יבש**.
- לשים לב: ב-**ω** מחלקים במשקל **המוצק** (Ws), **לא** במשקל הכולל.
- **n** מחלקים בנפח **הכולל**. **e** מחלקים בנפח **המוצק**.

## ⚖️ משקל מרחבי γ ("גמא") = משקל ÷ נפח

- **γt** (כולל) = **(Ws + Ww) / Vt** [kg/m³]
- **γd** (יבש) = **Ws / Vt** [kg/m³] ← רק המוצק, אבל מחלקים ב**כל** הנפח
- **γw** (מים) = **1,000 kg/m³** = **1 t/m³** = 1 ק"ג לליטר
- **Gs** (משקל סגולי של המוצקים) = **Ws / (Vs · γw)** ← בלי יחידות

## ✏️ דוגמה

מדגם: משקל כולל **2,000 kg**, מתוכו מים **200 kg**, נפח כולל **1.1 m³**.

1. Ws = 2,000 − 200 = **1,800 kg**
2. ω = 200 / 1,800 ≈ **0.111 = 11.1%**
3. γt = 2,000 / 1.1 ≈ **1,818 kg/m³**
4. γd = 1,800 / 1.1 ≈ **1,636 kg/m³**
5. בדיקה (רשות): γd = γt / (1 + ω) = 1,818 / 1.111 ≈ **1,636** ✓

## 🧠 לזכור

- 3 פאזות: **מוצק, מים, אוויר**. אוויר שוקל **0**.
- **ω = Ww / Ws** ו-**γd = Ws / Vt** (מסומנים בשקף כהכי חשובים).
- **γw = 1,000 kg/m³ = 1 t/m³**.
