# תרגול 9 · מרחק הובלה ועלויות (מרכז כובד)

> ⚡ **בקצרה:** מרחק ההובלה הממוצע = המרחק בין **מרכז הכובד של החפירה** ל**מרכז הכובד של המילוי**. ממנו: תפוקת דחפור, עלות, ועודף לפינוי.

---

## 🎯 הרעיון

- חותכים גבעה (**חפירה**) ומעבירים לשקע (**מילוי**).
- כל דלי עובר מרחק **אחר**.
- **הממוצע** = ממרכז כובד למרכז כובד.

## 📍 מרכז כובד של צורה

```
 RECTANGLE                 RIGHT TRIANGLE
 +-----------+             |\
 |     *     |             |  \
 +-----------+             | *  \
 |<-1/2->|                 +------\
                           |1/3|
```

- **מלבן:** באמצע → **1/2**.
- **משולש ישר-זווית:** ב-**1/3** מהצלע הישרה (2/3 מהקודקוד החד).
- קיצור למשולש: x = **ממוצע ה-x של 3 הקודקודים**.

## 🧮 נוסחאות

- **x מרכז כובד = Σ(A · x) / ΣA**
  - A = שטח הצורה [m²]
  - x = מרחק מרכז הצורה **מראשית הצירים** (= **זרוע**) [m]
- **מרחק הובלה = x מילוי − x חפירה**
- **נפח** = שטח בחתך האורך × **רוחב הכביש**
- **טבעי → מהודק:** × (1 − הידוק) · **טבעי → מופר:** × (1 + תפיחה)

## 🍳 מתכון

1. לחלק את אזור **החפירה** לצורות (מלבנים, משולשים).
2. טבלה: **צורה | שטח | זרוע | שטח × זרוע**.
3. **x חפירה** = Σ(שטח × זרוע) ÷ Σשטח.
4. אותו דבר ל**מילוי** → **x מילוי**.
5. **מרחק הובלה** = x מילוי − x חפירה.
6. תפוקת דחפור על המרחק הזה → [פתק 6](practice-excavation-output.md).
7. נפחים: חפירה ומילוי × **רוחב הכביש**.
8. **מאזן:** טבעי שצריך למילוי = מילוי ÷ (1 − הידוק). להשוות לחפירה → **עודף** או **חוסר**.
9. עודף לפינוי: × (1 + תפיחה) → ÷ נפח ארגז → **סבבי משאית** (לעגל **למעלה**).

## 🧪 דוגמה פתורה (מרכז כובד)

חפירה = **משולש** בין x = 0 ל-x = 6 (גובה 3, הצלע הישרה ב-x = 6) + **מלבן** בין 6 ל-10 (גובה 3).

1. משולש: A = 6 × 3 / 2 = **9 m²**, x = (0 + 6 + 6) / 3 = **4 m** → A·x = **36**
2. מלבן: A = 4 × 3 = **12 m²**, x = **8 m** → A·x = **96**
3. x חפירה = (36 + 96) / (9 + 12) = 132 / 21 ≈ **6.3 m**
4. אם x מילוי = **30 m** → מרחק הובלה ≈ **23.7 m**
5. בדיקה: 6.3 נמצא **בין 4 ל-8** (בין שני המרכזים) ✓

## 📝 סוגי שאלות בדף

- מרחק הובלה ממוצע (מרכזי כובד).
- תפוקת הדחפור על המרחק הזה.
- כמה עפר צריך, כשיש **תפיחה** ו**הידוק**.
- עלות ההעברה (דחפור + מפעיל, לשעה).
- עודף עפר → כמה **סבבי משאית**.

## ⚠️ טעויות נפוצות

- זרוע של משולש ב-**1/2** במקום ב-**1/3**.
- למדוד זרוע מקצה הצורה, ולא **מראשית הצירים**.
- לשכוח לכפול ב**רוחב הכביש**.
- לערבב **טבעי / מופר / מהודק** (משאית מעמיסה **מופר**).
- לעגל סבבי משאית **למטה**.

## 🧠 לזכור

- **x = Σ(A·x) / ΣA**
- משולש: **1/3** מהצלע הישרה.
- הובלה = **x מילוי − x חפירה**.
