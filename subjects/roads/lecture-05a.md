# מצגת 5 · חלק 1/4: למה מהדקים, ואיך מודדים גודל גרגרים

> ⚡ **בקצרה:** מהדקים קרקע כדי שהכביש **לא ישקע**. הבדיקה הראשונה במעבדה היא **ניפוי**: מעבירים את הקרקע דרך **סדרת נפות** ורואים כמה נשאר על כל אחת.

---

## 🏖️ הרעיון

- חול **רופף** בחוף: דורכים → **שוקעים**.
- חול **דחוס** ליד המים: דורכים → **לא שוקעים**.
- הידוק = **לדחוס** את הקרקע, כדי שתהיה כמו החול הדחוס.

## 🎯 חמש מטרות ההידוק

1. למנוע **שקיעות**.
2. ליצור משטח **חלק** להמשך העבודה.
3. **לחזק** את גוף הסוללה.
4. למנוע **חדירת מים**.
5. להעביר **עומסים** משכבה לשכבה, **ברצף**.

## 🔍 בקרת הידוק: מה בודקים?

- את **הביצוע**: איך מהדקים בשטח.
- את **החומרים**: האם הקרקע והמצע טובים.
- יש בדיקות **מעבדה** (חלקים 1–3) ובדיקות **אתר** (חלקים 3–4).

## ✂️ שלב 0: חלוקת הדגימה

דגימה מגיעה למעבדה → מחלקים אותה ל**חלקים שווים**, חלק לכל בדיקה.

1. **מחצה מדגמים** (Sample splitter): מכשיר שמפצל את הדגימה.
2. **חלוקה לפלחים**: פורשים על **פלטה ישרה** וחותכים לפלחים (כמו **פיצה**).

## 🥣 ניפוי (אנליזה מכנית)

- כמו **מסננת קמח**, רק הרבה מסננות אחת מעל השנייה.
- כל נפה מוגדרת לפי **גודל הגרגר שעובר** דרכה.
- גרגר גדול → **נשאר** למעלה. גרגר קטן → **עובר** למטה.

```
        sample
          |
          v
 [ 3"  ...  #4    ]  -> stays here = GRAVEL  (> 4.75 mm)
 [ #10 ...  #200  ]  -> stays here = SAND    (0.075 - 4.75 mm)
 [ pan            ]  -> FINES: silt + clay   (< 0.075 mm)
```

### 2 נפות שחייבים לזכור

- **#4 = 4.75 מ"מ** → הגבול בין **חצץ** ל**חול**.
- **#200 = 0.075 מ"מ** → הגבול בין **חול** ל**דקים** (טין/חרסית).

## 🧮 איך ממלאים את טבלת הניפוי

לכל נפה, 3 חישובים:

1. **% נשאר** = משקל שנשאר על הנפה [g] ÷ משקל כל הדגימה [g] × 100
2. **% שיור מצטבר** = סכום ה-% של הנפה הזו **ושל כל הנפות מעליה**
3. **% עובר** = 100 − % שיור מצטבר

**דוגמה מהמצגת:** דגימה של **6610 g**. כמה עובר את נפה **#4**?

1. נשאר על #4 ועל כל הנפות מעליה: 180 + 360 + 850 + 400 + 1200 + 850 + 790 = **4630 g**
2. שיור מצטבר: 4630 ÷ 6610 × 100 ≈ **70%**
3. עובר: 100 − 70 = **30%**
4. ✔️ בדיקה: בטבלה במצגת כתוב **30%** עובר את #4.

**מה זה אומר על הקרקע?**

- **70%** חצץ (נשאר עד #4)
- **4%** דקים (עובר את #200, לפי הטבלה)
- חול = 30 − 4 = **26%**
- ✔️ 70 + 26 + 4 = **100%**

## 🧠 לזכור

- הידוק → **לא שוקע**, **מים לא חודרים**, **עומס עובר ברצף**.
- **#4 = 4.75 מ"מ** (חצץ/חול). **#200 = 0.075 מ"מ** (חול/דקים).
- **% עובר = 100 − % שיור מצטבר**.
