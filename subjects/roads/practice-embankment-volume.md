# תרגול 8 · נפח סוללת עפר טרפזית

> ⚡ **בקצרה:** חתך סוללה = **טרפז** = מלבן + 2 משולשים → **T = B·H + S·H²**. נפח = **ממוצע שטחים × מרחק**, תחנה אחרי תחנה.

---

## 🏔️ הרעיון

- הכביש **מישורי** (בלי עלייה). הקרקע מתחתיו **לא ישרה**.
- ממלאים עפר → **סוללה**. החתך שלה = **טרפז**.
- הגובה **H** משתנה מתחנה לתחנה → גם השטח.

## 📐 הטרפז

```
              B (top width)
          +---------+
         /|         |\
        / |    H    | \      side slope 1:S
       /  |         |  \     (1 up : S sideways)
      +---+---------+---+
       S*H     B     S*H
```

- **שיפוע 1:S** = עולים **1**, זזים **S** הצידה.
- כל משולש: בסיס **S·H**, גובה **H** → שטח **S·H² / 2**.

## 🧮 נוסחאות

- **מלבן:** D = B · H
- **2 משולשים:** E = S · H²
- **טרפז:** T = D + E = **B·H + S·H²**
- **שטח ממוצע:** X = (T1 + T2) / 2
- **נפח בין תחנות:** Z = X · Y (Y = מרחק בין התחנות)
- **נפח כולל** = סכום כל ה-Z

## 🍳 מתכון (טבלה)

עמודות: **תחנה · H · B · D · E · T · X · Y · Z**

1. למלא **תחנה**, **H**, **B** (נתונים).
2. בכל שורה: **D**, **E**, **T**.
3. מהשורה **השנייה** והלאה: **X** (עם השורה הקודמת), **Y**, **Z**.
4. לסכם את Z → **נפח כולל**.
5. **בדיקה:** הנפח ≈ שטח ממוצע × אורך כולל?

## 🔀 כשהשיפוע תלוי בגובה

- בתרגיל 2: **H ≤ 2 m → 1:4**, **H > 2 m → 1:5**.
- אם H חוצה את **2 m** בין שתי תחנות → **להוסיף תחנת ביניים** בנקודה שבה H = 2.
- למצוא אותה ב**אינטרפולציה** בין התחנות.
- בכל שורה: לבחור **S לפי ה-H שלה**.

## 🧪 דוגמה פתורה

B = **10 m**, שיפוע **1:2**. תחנה 0: H = **1 m**. תחנה 20: H = **2 m**.

1. תחנה 0: D = 10 × 1 = **10**, E = 2 × 1² = **2** → T = **12 m²**
2. תחנה 20: D = 10 × 2 = **20**, E = 2 × 2² = **8** → T = **28 m²**
3. X = (12 + 28) / 2 = **20 m²**
4. Z = 20 × 20 = **400 m³**
5. בדיקה: בגובה ממוצע 1.5 m → T = 10·1.5 + 2·1.5² = **19.5** ≈ 20 ✓

## ⚠️ טעויות נפוצות

- **S·H** במקום **S·H²** (לשכוח לרבע את H).
- לחלק שוב ב-2: **S·H² כבר כולל שני משולשים**.
- לחשב X ב**שורה הראשונה** (אין לה שורה קודמת).
- לשכוח **תחנת ביניים** כשהשיפוע מתחלף.
- לקרוא 1:2 הפוך (2 למעלה, 1 הצידה).

## 🧠 לזכור

- **T = B·H + S·H²**
- **V = (T1 + T2) / 2 × מרחק**
- שיפוע משתנה → **תחנת ביניים**.
