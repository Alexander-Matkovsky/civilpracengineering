# תרגול 5 · הידוק קרקע

> ⚡ **בקצרה:** יש **רטיבות אחת** (ω_op) שבה הקרקע נדחסת **הכי טוב** (γd max). בשטח דורשים **אחוז** מה-γd max, בתוך **תחום רטיבות**.

---

## 🏖️ הרעיון

- חול **יבש** → מתפורר, לא נדחס.
- חול **רטוב מדי** → המים תופסים מקום. "מרק".
- חול **לח במידה** → נדחס הכי טוב. (כמו ארמון חול.)

## 📈 עקום ההידוק (בדיקת מעבדה)

```
  gd
   |          *   <- gd max
   |       *     *
   |     *         *
   |   *             *
   +----------+------------> w (%)
            w_op
     dry side | wet side
```

- **הפסגה** = **γd max** (הכי דחוס), ברטיבות **ω_op** (אופטימלית).

## 🧮 נוסחאות

- **ω = (רטוב − יבש) / יבש**
- **γt = משקל / נפח**
- **γd = γt / (1 + ω)** = משקל יבש / נפח
- **γd נדרש בשטח = p × γd max** (p למשל **90%** או **95%**)
- יחידות: g/cm³ = kg/L = t/m³ (אותו מספר)

## 🍳 מתכון A: טבלת מעבדה → עקום

1. קרקע רטובה = (כוס + רטוב) − **כוס**.
2. קרקע יבשה = (כוס + יבש) − **כוס**.
3. ω = (רטוב − יבש) / יבש.
4. γd = יבש / נפח הכוס.
5. לשרטט: **ω** בציר X, **γd** בציר Y.
6. **הפסגה** → ω_op ו-γd max.

## 🍳 מתכון B: דרישה בשטח

1. γd נדרש = p × γd max.
2. למתוח קו **אופקי** בגובה הזה על העקום.
3. שתי נקודות החיתוך → **ω מינימום** ו-**ω מקסימום**.

## 👷 מתכון C: הערות המפקח (בדיקה כל 100 m)

| מצב | הערה |
|---|---|
| ω בתחום **וגם** γd ≥ נדרש | **תקין** |
| ω בתחום, אבל γd **נמוך** | **לעבור שוב עם מכבש** |
| ω **גבוה** מדי | להפוך, **לייבש**, להדק מחדש |
| ω **נמוך** מדי | להפוך, **להרטיב**, להדק מחדש |

## 🚚 מתכון D: כמה לחפור? כמה מים?

1. γd בבור = γt / (1 + ω בבור)
2. **מוצק נדרש** = נפח סוללה × γd נדרש
3. **נפח חפירה** = מוצק נדרש ÷ γd בבור
4. מים קיימים = ω בבור × מוצק
5. מים נדרשים = ω נדרש × מוצק
6. **הפרש** חיובי → **להוסיף**. שלילי → **לייבש**. (1 טון מים = 1 m³)

## 🧪 דוגמה פתורה (מתכון D)

בור: γt = **1.9 t/m³**, ω = **10%**. נדרש: **500 m³** סוללה, γd = **2.0 t/m³**, ω = **14%**.

1. γd בבור = 1.9 / 1.10 ≈ **1.727 t/m³**
2. מוצק נדרש = 500 × 2.0 = **1000 t**
3. נפח חפירה = 1000 / 1.727 ≈ **579 m³**
4. מים קיימים = 0.10 × 1000 = **100 t**
5. מים נדרשים = 0.14 × 1000 = **140 t**
6. להוסיף **40 t = 40 m³** מים
7. בדיקה: חופרים **יותר** מ-500 m³, כי בבור הקרקע **פחות דחוסה** ✓

## ⚠️ טעויות נפוצות

- לשכוח להחסיר את **משקל הכוס**.
- ω מחלקים ב-**יבש**, לא ברטוב.
- לחשב מים לפי **נפח** הסוללה במקום לפי **משקל המוצק**.
- לקחת **γt** של הבור במקום **γd** שלו.
- לבדוק רק γd, ולשכוח לבדוק ש-**ω בתחום**.

## 🧠 לזכור

- **פסגת העקום** = ω_op ו-γd max.
- **γd = γt / (1 + ω)**
- המוצק **לא משתנה** בין הבור לסוללה. משתנים רק **המים** וה**נפח**.
