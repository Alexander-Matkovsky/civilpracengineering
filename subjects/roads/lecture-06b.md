# מצגת 6 · חלק 2/5: ביטומן, דירוג ובדיקת מרשל

> ⚡ **בקצרה:** ביטומן = **הדבק השחור** באספלט. בוחרים אותו לפי **סוג הפרויקט** ו**האקלים**: מקום **חם** או תנועה **כבדה** → ביטומן **קשה** יותר (מספר **נמוך**). בדיקת **מרשל** מוצאת את התערובת הכי מתאימה.

---

## 🍯 הרעיון

- **דבש במקרר** = קשה. **דבש בשמש** = נוזל.
- גם ביטומן **מתרכך בחום**.
- לכן במקום חם צריך ביטומן **קשה** יותר, שלא יימרח.

## 📖 אספלט או ביטומן?

- שתי המילים משמשות **לאותו דבר**: חומר **שחור** ש**קושר** את התערובת. נקרא גם **"זפת"**.
- לפי תקן **ASTM D8**: אספלט = חומר **שמורכב מביטומן**.

## 🛢️ 3 סוגי ביטומן

1. **ביטומן אספלטי** (asphalt cement): הביטומן **הבסיסי**.
2. **ביטומן שפיך** (liquid asphalt): ביטומן **מומס** בממיסים **נפטיים**.
3. **אמולסיית ביטומן** (emulsified asphalt): **טיפות זעירות** של ביטומן **בתוך מים**, בעזרת חומר מתחלב.

## 🌡️ דירוג לפי חדירה

- מודדים את **הסמיכות** של הביטומן ב-**25°C**, בבדיקת **חדירה** (penetration test).
- בודקים כמה עמוק **מחט** נכנסת. (המספר = עומק החדירה ביחידות של 0.1 מ"מ)
- נכנסת **מעט** → ביטומן **קשה** → מספר **נמוך**.

```
  40-50    60-70    85-100    120-150    200-300
  HARD <-------------------------------------> SOFT
```

## 🗺️ איזה דירוג לבחור?

תלוי ב-2 דברים: **סוג הפרויקט** ו**האקלים**.

| שימוש | אקלים **קר** | **ממוזג/חם** |
|---|---|---|
| שדה תעופה (מסלולים, חניה) | 85-100 | 60-70 |
| כביש, תנועה **כבדה** | 85-100 | 60-70 |
| כביש, תנועה **בינונית–קלה** | 120-150 | 85-100 |
| רחוב, תנועה **כבדה** | 85-100 | 60-70 |
| רחוב, תנועה **בינונית–קלה** | 85-100 | 85-100 |
| חניון **תעשייתי** | 60-70 | 60-70 |
| חניון **מסחרי** | 85-100 | 60-70 |

- כלל אצבע: **חם** או **כבד** → **60-70** (קשה יותר).

## 🏷️ רישום בחוזה: PG X-Y

- **PG** = Performance Grade (ציון ביצועים)
- **X** = טמפרטורה **מקסימלית** של המיסעה [°C]
- **Y** = טמפרטורה **מינימלית** של המיסעה [°C]

**דוגמה נפוצה: PG 70-10**

1. הביטומן מחזיק עד **70°C** בחום.
2. הביטומן מחזיק עד **−10°C** (מינוס 10) בקור.

## 🔬 בדיקת מרשל (Marshall)

- **מטרה:** להעריך תכונות **פיזיקליות ומכניות** של תערובת אספלט **חמה**, ולפקח על **הייצור וההנחה**.
- **איך:**
  1. מכינים **כמה מדגמים**.
  2. בכולם: **אותם** אגרגטים (לפי התקן) ו**אותה** אנרגיית הידוק.
  3. רק **תכולת הביטומן** משתנה.
  4. בודקים ומשווים.
- **התוצאה:** התערובת **הכי מתאימה** לפרויקט: **חוזק**, **תכולת ביטומן אופטימלית**, **דירוג אגרגט**.

## 🧠 לזכור

- 3 סוגים: **בסיסי**, **שפיך** (בממיס), **אמולסיה** (במים).
- מספר חדירה **נמוך** = **קשה**. חם/כבד → **60-70**.
- **PG 70-10** = מקס' **70°C**, מינ' **−10°C**. **מרשל** = תכולת ביטומן אופטימלית.
