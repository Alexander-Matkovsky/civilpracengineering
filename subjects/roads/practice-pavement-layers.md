# תרגול 2 · שכבות מיסעת כביש

> ⚡ **בקצרה:** כביש אספלט = **5 שכבות**. מלמטה למעלה: **שתית → תשתית → מקשרת → נושאת → ציפוי**.

---

## 🎂 הרעיון

- כביש בנוי כמו **עוגת שכבות**.
- לכל שכבה **תפקיד אחד**.
- השאלה (מבחן מה"ט, **5 נק'**): לסדר את השכבות **מלמטה למעלה**, ולהתאים לכל אחת **תפקיד**.

## 🧱 התמונה

```
  +-----------------------------+  5  WEARING   (tsipui)
  +-----------------------------+  4  BEARING   (nosset)
  +-----------------------------+  3  BINDER    (mekasheret)
  +-----------------------------+  2  BASE      (tashtit)
  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~  1  SUBGRADE  (shtit) = ground
```

## 📋 שכבה ↔ תפקיד

| # | שכבה | תפקיד |
|---|---|---|
| 1 (למטה) | **שתית** | **מגע** בין המיסעה לקרקע הקיימת |
| 2 | **תשתית** | **בסיס** לשכבה האספלטית |
| 3 | **מקשרת** | **מחברת** בין התשתית לשכבה הנושאת |
| 4 | **נושאת** | **מקבלת את העומס** |
| 5 (למעלה) | **ציפוי** | פחות **רעש**, יותר **חיכוך**, **ניקוז** |

## 🔍 מתכון: לפתור בלי לשנן

1. **למצוא את הקצוות:**
   - מה נוגע ב**אדמה**? → **שתית** (למטה).
   - מה נוגע ב**צמיגים**? → **ציפוי** (רעש, חיכוך).
2. **רמז בתפקיד:** "מחברת בין התשתית לנושאת" → המקשרת **ביניהן**.
3. **רמז בשם:** "נושאת" → נושאת את **העומס**.
4. "בסיס לאספלט" → מה שנשאר: **תשתית**, מעל השתית.
5. **בדיקה:** לקרוא מלמטה למעלה. כל שכבה נשענת על הקודמת?

## 🚗 דוגמה מהחיים

- הצמיג נוגע ב**ציפוי** → צריך **אחיזה** ומעט **רעש**.
- המשקל של המשאית עובר ל**שכבה הנושאת**.
- ה**שתית** = האדמה המהודקת שעליה הכול עומד.

## ⚠️ טעויות נפוצות

- **שתית** ו**תשתית** נשמעות דומה: **שתית = הכי למטה** (האדמה). תשתית = מעליה.
- לסדר **מלמעלה למטה**, כשהשאלה מבקשת **מלמטה למעלה**.
- (רשות) בשטח, "שכבה מקשרת" (binder) היא לרוב שכבת אספלט **מעל** הנושאת. **בשאלה הזו:** להיצמד לתפקידים שכתובים בה.

## 🧠 לזכור

- **שתית → תשתית → מקשרת → נושאת → ציפוי**
- השם רומז על התפקיד: **נושאת = עומס**, **מקשרת = מחברת**.
- ציפוי = **רעש, חיכוך, ניקוז**.
