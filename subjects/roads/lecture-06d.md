# מצגת 6 · חלק 4/5: הובלה, פיזור וכבישת אספלט

> ⚡ **בקצרה:** מביאים אספלט **חם (140–160°C)** במשאית **מכוסה**. **מכונת גמר** מפזרת אותו ברוחב **2.5–6 מ'**. אחר כך **מכבשים** (ויברציוני + פנאומטי) כובשים אותו.

---

## 🍕 הרעיון

- אספלט הוא כמו **פיצה**: צריך להגיע **חם**.
- קר מדי → אי אפשר לפזר ולהדק אותו טוב.
- לכן הכול קורה **מהר** וב**רצף**: משאית → מגמר → מכבש.

## 🚚 הובלה

1. משאיות **סגורות** ממתכת.
2. לפני העמסה: לוודא ש**ארגז** המשאית **נקי**.
3. לשמור על **החום**: לכסות ב**ברזנט**.

## 🌡️ טמפרטורה

- לבדוק (במדחום) שהטמפרטורה **בטווח הנדרש** לתערובת.
- הטווח הנפוץ: **140–160°C**.

## 🛣️ פיזור: מכונת הגמר (מפזרת אספלט)

```
 TRUCK -> [HOPPER] -> conveyors -> [AUGER] -> [SCREED] -> new layer
          (front)                              (rear)
```

1. המשאית שופכת לתוך **הארגז**, בחזית המכונה.
2. **מסועים** מעבירים את האספלט **אחורה**, אל **בורג הפיזור** (חילזון).
3. הבורג **מפזר** את האספלט על התשתית.
4. **המגהץ** (מחומם) קובע את **העובי** ומשפר את **העבידות**.

מספרים וכללים:

- **מהירות** המגמר = לפי **קצב** הגעת המשאיות.
- **רוחב** פיזור: **2.5–6 מ'**.
- המגמר עושה את **הכבישה הראשונה**.
- תיקונים ידניים: **את חפירה** ו**מגרפה**.

## 🚜 כבישת האספלט

- הכי חשובה ל**תכונות** הכביש הגמור.
- **קשיחות** טובה → הכביש:
  1. **מפזר** את העומס
  2. עומד במאמצי **לחץ** ו**מתיחה**
  3. מתנגד ל**חריצה** (שקעים בנתיב הגלגלים)
- אחרי המגמר כובשים עם:
  - **מכבש ויברציוני** (גליל פלדה רוטט)
  - **מכבש פנאומטי** (גלגלי גומי)

## 🧠 לזכור

- הובלה: משאית **נקייה**, **סגורה**, **מכוסה בברזנט**.
- טמפרטורה: **140–160°C**. רוחב פיזור: **2.5–6 מ'**.
- כבישה: **ויברציוני + פנאומטי** → קשיחות → מונע **חריצה**.
