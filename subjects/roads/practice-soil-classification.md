# תרגול 4 · מיון קרקעות (שיטת המיון האחידה)

> ⚡ **בקצרה:** נותנים לקרקע **שם של 2 אותיות**. גסה (חצץ / חול) → לפי **ניפוי** (Cu, Cc). דקה (טין / חרסית) → לפי **LL ו-PL**.

---

## 🔤 האותיות

| אות | פירוש |
|---|---|
| **G** | חצץ (Gravel) |
| **S** | חול (Sand) |
| **M** | טין (Silt) |
| **C** | חרסית (Clay) |
| **W** | מדורג **טוב** (Well) |
| **P** | מדורג **רע** (Poor) |
| **L** | פלסטיות **נמוכה** (Low) |
| **H** | פלסטיות **גבוהה** (High) |

- **SW** = חול מדורג טוב.
- **CL** = חרסית בפלסטיות נמוכה.

## 🪨 חלק 1: קרקע גסה (חצץ / חול)

- **מדורג טוב (W)** = יש **מכל הגדלים**. הקטנים ממלאים חורים בין הגדולים.
- **מדורג רע (P)** = כמעט **גודל אחד**, או שחסרים גדלי ביניים.

```
  W (well graded)            P (poorly graded)
  % passing                  % passing
  100 |\                     100 |  |
      | \                        |  |
      |  \                       |  |
      |   \                      |  |
    0 +----\----> size         0 +--+------> size
       wide range                 narrow range
```

**נוסחאות:**

- **Cu = d60 / d10** (מקדם אחידות)
- **Cc = d30² / (d10 · d60)** (מקדם עקמומיות)
- **dXX** = גודל הגרגר ש-**XX% עוברים** דרכו [mm]

**תנאים ל-W (שניהם!):**

- חול: **Cu ≥ 6** · חצץ: **Cu ≥ 4**
- וגם: **1 ≤ Cc ≤ 3**
- תנאי אחד נכשל → **P**

## 📊 מתכון: מטבלת ניפוי לשם

1. לסכם את **כל** המשקלים → משקל כולל.
2. לכל נפה: **% שיור** = שיור ÷ כולל × 100.
3. **שיור סכומי** = לצבור מהנפה הגדולה לקטנה.
4. **% עובר** = 100 − שיור סכומי.
5. **חצץ או חול?**
   - X = (שיור סכומי בנפה **#4**) ÷ (שיור סכומי בנפה **#200**) × 100
   - X > 50 → **G** · X ≤ 50 → **S**
6. לשרטט עקום דירוג (ציר הגודל **לוגריתמי**).
7. לקרוא **d10, d30, d60**.
8. לחשב Cu ו-Cc → **W** או **P**.

## 🧪 דוגמה פתורה

חול. d10 = **0.1 mm**, d30 = **0.4 mm**, d60 = **1.2 mm**.

1. Cu = 1.2 / 0.1 = **12** → 12 ≥ 6 ✓
2. Cc = 0.4² / (0.1 × 1.2) = 0.16 / 0.12 ≈ **1.33** → בין 1 ל-3 ✓
3. שני התנאים עברו → **SW**
4. בדיקה: חול = S, מדורג טוב = W ✓

## 🧱 חלק 2: קרקע דקה (טין / חרסית)

- עוברת **נפה #200**. בודקים איך היא מגיבה ל**מים**.
- **PL** = גבול פלסטיות (בדיקת "**הנחשים**").
- **LL** = גבול נזילות (בדיקת "**ההקפצות**").
- **PI = LL − PL** (אינדקס פלסטיות) → מראה **פוטנציאל תפיחה**.
- **PI גדול** = תופחת יותר = **פחות טובה** כבסיס לכביש.

**מתכון (גרף הפלסטיות):**

1. PI = LL − PL
2. לסמן נקודה: **LL** בציר X, **PI** בציר Y.
3. מעל **קו A** → **C** (חרסית). מתחת → **M** (טין).
4. LL **מעל 50** → **H**. מתחת → **L**.

```
 PI
  |              /  A-line
  |     C       /
  |   (clay)   /
  |           /     M
  |          /    (silt)
  +---------|------------> LL
     L      50      H
```

(רשות) קו A: PI = 0.73 · (LL − 20)

## ⚠️ טעויות נפוצות

- **d10** = 10% **עוברים** (לא נשארים).
- לבדוק רק Cu ולשכוח את **Cc**.
- לבלבל: **6** לחול, **4** לחצץ.
- ציר הגודל **לוגריתמי**: לא לקרוא אותו כמו ציר רגיל.
- בדף העבודה: את **השיור הסכומי** מסמנים על ציר ה-Y **הימני**.
- PI = **LL − PL** (לא הפוך).

## 🧠 לזכור

- **Cu = d60/d10**, **Cc = d30²/(d10·d60)**
- W: Cu ≥ 6 (חול) / ≥ 4 (חצץ), **וגם** 1 ≤ Cc ≤ 3.
- דקה: **PI = LL − PL**. מעל קו A = **C**. LL > 50 = **H**.
