# מצגת 4ב: בדיקת פרוקטור ועקום הידוק

> ⚡ **בקצרה:** במעבדה מהדקים דגימות עם **פטיש**: פרוקטור **רגיל ≈ 590** או **מוגבר ≈ 2,700 kJ/m³**. מכמה בדיקות בונים **עקום הידוק**. **נקודת השיא** = **γd מקסימלי** + **ω אופטימלית**.

---

## 🔨 שתי בדיקות מעבדה ("פטיש 1", "פטיש 2")

| | **פטיש 1: פרוקטור רגיל (סטנדרד)** | **פטיש 2: פרוקטור מוגבר (מודיפייד)** |
|---|---|---|
| שכבות | **3** | **5** |
| הקשות לכל שכבה | 25 | 25 |
| מסת הפטיש | **2.5 ק"ג** | **4.54 ק"ג** |
| גובה נפילה | **30.48 ס"מ** | **45.7 ס"מ** |
| נפח הכלי | 0.944 ליטר | 0.944 ליטר |

- טריק: **מוגבר = יותר מהכול**: יותר שכבות, פטיש כבד יותר, נפילה גבוהה יותר.
- **אותו דבר** בשניהם: **25 הקשות** ו**אותו כלי**.

## 🧮 אנרגיית ההידוק

**E = m · g · H · N · L / V** [J/m³]

- **m** = מסת הפטיש [kg]
- **g** = תאוצת הכובד = **9.81** [m/s²]
- **H** = גובה הנפילה [m]
- **N** = מספר הקשות לשכבה
- **L** = מספר השכבות
- **V** = נפח הכלי [m³] (0.944 ליטר = **0.944 · 10⁻³ m³**)

**פטיש 1 (רגיל):**

1. 2.5 · 9.81 · 0.3048 · 25 · 3 ≈ **561 J**
2. 561 ÷ (0.944 · 10⁻³) ≈ 594,000 J/m³
3. ≈ **590 kJ/m³**

**פטיש 2 (מוגבר):**

1. 4.54 · 9.81 · 0.457 · 25 · 5 ≈ **2,544 J**
2. 2,544 ÷ (0.944 · 10⁻³) ≈ 2,695,000 J/m³
3. ≈ **2,700 kJ/m³**

בדיקה: 2,700 ÷ 590 ≈ **4.6** → במוגבר משקיעים בערך **פי 4.5** אנרגיה ✓

## 📈 עקום ההידוק

1. עושים **4–5 בדיקות**, כל אחת ב-**ω אחרת**.
2. בכל בדיקה מודדים **γd**.
3. מציירים: **ω** בציר X, **γd** בציר Y.
4. **נקודת השיא** = **γd מקסימלי** ו-**ω אופטימלית (ωopt)**.

```
 gamma_d
    |               *    <- peak: gamma_d max
    |           *       *
    |       *               *
    |   *                       *
    +---------------+---------------> w (%)
                  w_opt
       too dry          too wet
```

- דוגמה מהחיים: **ארמון חול בים**. חול יבש → מתפורר. רטוב מדי → נוזל. **רטיבות נכונה** → מחזיק הכי טוב.
- העקום **ייחודי** לכל **קרקע** ולכל **רמת אנרגיה**.
- **יותר אנרגיה** → אפשר להדק **לרמה גבוהה יותר** (γd מקסימלי גבוה יותר).
- (רשות, לא בשקף: בדרך כלל עם יותר אנרגיה, ωopt **יורדת** קצת.)

## 🧠 לזכור

- רגיל: **3 שכבות, 2.5 ק"ג, 30.48 ס"מ** → **≈ 590 kJ/m³**.
- מוגבר: **5 שכבות, 4.54 ק"ג, 45.7 ס"מ** → **≈ 2,700 kJ/m³**.
- שיא העקום → **γd max** ו-**ωopt**.
