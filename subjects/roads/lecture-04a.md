# מצגת 4א: הידוק קרקע: מה, למה ואיפה

> ⚡ **בקצרה:** הידוק = **מקטינים את החללים** (האוויר) בקרקע → **γd עולה**. המטרה: גרגרים **צמודים** שמעבירים **עומס** טוב. עושים את זה עם **מכבש**.

---

## 🧊 מה קורה לחללים? (הקובייה האלמנטרית)

```
                 +-------+
                 |       |
                 |       |
 +-------+       |  AIR  |
 |       |       |       |       +-------+
 |  AIR  |       |       |       |  AIR  |
 +-------+       +-------+       +-------+
 | WATER |       | WATER |       | WATER |
 +-------+       +-------+       +-------+
 | SOLID |       | SOLID |       | SOLID |
 +-------+       +-------+       +-------+
  NATURAL        LOOSENED        COMPACTED
```

- **טבעית** → חופרים → **מופרת**: יותר אוויר, הנפח **גדל**.
- **מהודקת**: פחות אוויר, הנפח **קטן**.
- **המוצק והמים לא משתנים.** רק **האוויר**.
- לכן **γd = Ws / Vt** עולה: אותו Ws, אבל **Vt קטן** יותר.

## 💪 למה להדק? 4 יתרונות

1. **מחזק** את הקרקע.
2. **מייצב ומקשיח** אותה.
3. מונע **שקיעות**: מיידיות וגם **ארוכות טווח**.
4. מונע או מעכב **חדירת מים** לקרקע.

> המטרה היא **לא** "צפיפות" כשלעצמה. המטרה: גרגרים **צמודים** → יותר **נקודות מגע** → הקרקע **מעבירה עומסים** טוב יותר.

## 🏗️ איפה חייבים להדק?

1. **סוללת עפר** לרכבת, כביש, גשר → מחזק את **הדפנות**, מונע **שקיעות ותזוזות**.
2. **יסודות** של מבנים → **יציבות**, בלי שקיעות.
3. **מילוי מאחורי קיר תומך** → יציבות, בלי שקיעות.
4. **סביב צינור** → יוצר "**מסגרת**" כדי שהצינור **לא יימעך** פנימה.

## 🔬 פרוקטור (1933): 4 פרמטרים

**פרוקטור** ייסד את עקרונות ההידוק. ההידוק תלוי ב-4 דברים:

1. **γd**: משקל מרחבי יבש
2. **ω**: תכולת רטיבות
3. **מאמץ ההידוק** = **אנרגיית** ההידוק
4. **סוג הקרקע**

**מאמץ הידוק** = כמה **אנרגיה** משקיעים בקרקע:

- **בשטח**: מספר **המעברים של המכבש** על אותו אזור.
- **במעבדה**: מספר **הקשות הפטיש** על הדגימה.

## 🧠 לזכור

- הידוק = **פחות אוויר** → **γd עולה**.
- 4 יתרונות: **חוזק, יציבות, בלי שקיעות, פחות חדירת מים**.
- פרוקטור: **γd, ω, אנרגיה, סוג קרקע**.
