# מצגת 2: עבודות עפר וציוד מכני הנדסי

> ⚡ **בקצרה:** עבודות עפר = **לחפור, להזיז, למלא ולהדק** קרקע בעזרת **צמ"ה**. הסדר: **מדידה** → **חישוף (~20 ס"מ)** → **חפירה**.

---

## 🚜 מה זה עבודות עפר?

- כל עבודה שמשנה את **פני הקרקע**: **חפירה**, **מילוי**, **הובלה**, **הידוק**.
- עושים אותה עם **צמ"ה** = **צ**יוד **מ**כני **ה**נדסי.
- דוגמה: **מחפר** ממלא **משאיות** בעפר מהמגרש.

## ⚖️ זחלי או גלגלים (אופני)?

**זחלי** (שרשראות) עדיף כש...

1. הקרקע **רכה** או **בוצית** → אחיזה טובה.
2. השטח **סלעי**, **הררי** או **משופע**.
3. צריך **לחץ מגע נמוך** על הקרקע.
4. צריך **כף גדולה** וכלי **רב-תכליתי**.

**אופני** (גלגלים) עדיף כש...

1. צריך **לנסוע מהר** בתוך האתר.
2. עוברים **בין אתרים** בלי להעמיס על משאית.
3. נוסעים על **אספלט** בלי להרוס אותו.
4. רוצים **תפוקה** גבוהה יותר.

> טריק: זחלי = **טנק** (חזק בשטח קשה). אופני = **משאית** (מהיר ונייד).

## 🧰 הכלים העיקריים

| כלי | מה הוא עושה |
|---|---|
| **דחפור** | **דוחף** עפר עם להב מקדימה. מאחור: שן לפירוק קרקע קשה |
| **מעמיס / יעה** | כף גדולה מקדימה. **מעמיס** עפר ומצע על משאיות |
| **מחפרון (JCB)** | **כף מקדימה + זרוע חפירה מאחור**. קטן ורב-שימושי |
| **בובקט** | מעמיס **קטן** למקומות **צפופים** |
| **מחפר / באגר** | **חופר** תעלות ויסודות, ממלא משאיות |
| **מפלסת** | להב ארוך באמצע. **מיישרת** שכבות בדיוק לגובה |
| **משאית עפר** | **מובילה** עפר (יש גם משאית מפרקית לשטח) |
| **מגרסה** | **גורסת** סלע לחצץ ולמצע |
| **מכבש** | **מהדק** שכבות (תוף פלדה או גלגלי גומי) |
| **מכלית מים** | **מרטיבה** את הקרקע לפני הידוק |
| **פטיש חציבה** | מותקן על מחפר. **שובר סלע** |

## 📋 תוכניות ביצוע

1. **תוכנית אתר כללית**
2. **תוכנית חפירה / מילוי**
3. **תוכנית הובלת עפר**
4. **חתכים**: פני קרקע **טבעיים** מול פני קרקע **מוגמרים**
5. **מפרטים**: איך לבצע
6. **כתב כמויות**: מה וכמה

```
            CUT (dig)
         ____________
        /            \
 ======/==============\========/=====  <- finished level
                       \      /
                        \____/
                      FILL (add)
 ( the / \ line = natural ground )
```

- קרקע טבעית **מעל** הגובה המתוכנן → **חפירה**.
- קרקע טבעית **מתחת** לגובה המתוכנן → **מילוי**.

## 🏁 תחילת עבודה, לפי הסדר

1. **מדידה וסימון**: **מודד מוסמך** תוקע **יתדות**: גבולות המגרש, גובהי חפירה, תשתיות.
2. **חישוף**: מסירים את השכבה העליונה עם **צמחים ושורשים**, בדרך כלל עד **20 ס"מ**. למה?
   - מנקה **חומר אורגני** ולכלוך.
   - נותן משטח **נקי** למדידה ולסימון.
   - חושף נקודות רגישות: **בורות** ו**תשתיות קיימות**.
3. **חפירה כללית**: חפירה **במכונות** על שטח **רחב**, בלי מגבלות מיוחדות.
   - העפר הולך ל**מילוי** באתר ומפוזר שם, **או**
   - **מועמס** על משאיות ויוצא מהאתר.
   - כלים: **דחפור, יעה, באגר, משאית**.
4. חופרים עד **גובה המגרש הדרוש**, ולפעמים עמוק יותר ל**מרתפים / יסודות**.

```
 SURVEY -> STRIPPING -> EXCAVATION -> FILL (on site)
 (stakes)   (~20 cm)               \-> TRUCK -> approved site
```

> ⚠️ עודפי עפר ופסולת → **רק לאתר מוסדר**. אסור לשפוך בשטח פתוח.

## 🧠 לזכור

- **צמ"ה** = ציוד מכני הנדסי.
- זחלי = **שטח קשה**. אופני = **מהירות, ניידות, תפוקה**.
- סדר: **מדידה → חישוף (~20 ס"מ) → חפירה**.
