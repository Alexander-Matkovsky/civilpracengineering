# תרגול 6 · תפוקת כלי חפירה

> ⚡ **בקצרה:** תפוקה = **כמה m³ טבעיים בשעה**. **Q = נפח טבעי בסבב × סבבים בשעה × ניצולת**. ממנה: **ימים** ו**עלות**.

---

## 🚜 הרעיון

- דחפור / משאית עושים **סבבים**: לוקחים → מובילים → חוזרים.
- כל סבב מעביר **כף אחת**.
- אבל בכף הקרקע **תפוחה** (מופרת) → יש בה **פחות** קרקע טבעית.

```
   NATURAL        LOOSE          COMPACTED
   1.0 m3   -->   1.2 m3   -->   0.9 m3
   (ground)       (bucket)       (road)
```

## 📋 4 הרכיבים

1. **קיבולת הכף** [m³ מופר]
2. **אחוז תפיחה:**
   - חמרה **12%** · טין **25%** · חרסית **40%** · סלע **65%**
3. **ניצולת** (כמה מהשעה עובדים באמת):
   - טובה **92%** (55 דק') · בינונית **83%** (50 דק') · מוגבלת **67%** (40 דק')
4. **משך סבב** = הובלה + חזרה + זמנים קבועים (העמסה, פריקה, החלפת הילוכים)

## 🧮 נוסחאות

- **זמן = מרחק / מהירות**
- km/h → m/min: **× 1000 / 60** (למשל 3 km/h = **50 m/min**)
- **V טבעי בסבב = V כף / (1 + תפיחה)**
- **סבבים בשעה = 60 / T** (T בדקות)
- **Q = V טבעי × (60 / T) × ניצולת** [m³/h]
- **שעות = נפח כולל / Q** → **ימים = שעות / 8** → לעגל **למעלה**
- **עלות = ימים × 8 × (כלי + מפעיל)** [₪/שעה]
- **עלות ל-m³ = עלות כוללת / נפח**

## 🍳 מתכון

1. להמיר **מהירויות** ל-m/min, ו**שניות** לדקות.
2. **T** = הלוך + חזור + קבוע.
3. **V טבעי** = כף ÷ (1 + תפיחה).
4. **Q** = V טבעי × 60/T × ניצולת.
5. שעות → ימים (**לעגל למעלה** לימים שלמים).
6. עלות כוללת → עלות ל-m³.
7. **בדיקה:** היחידות של Q הן **m³/h**?

## 🧪 דוגמה פתורה

דחפור. מרחק **50 m**. כף **3 m³**, טין (**25%**), ניצולת **83%**. דחיפה **3 km/h**, חזרה **6 km/h**, הילוכים **12 s**. להעביר **3000 m³**. דחפור **300 ₪/h**, מפעיל **60 ₪/h**.

1. 3 km/h = 50 m/min → הלוך: 50 / 50 = **1.0 min**
2. 6 km/h = 100 m/min → חזור: 50 / 100 = **0.5 min**
3. 12 s = **0.2 min**
4. T = 1.0 + 0.5 + 0.2 = **1.7 min**
5. V טבעי = 3 / 1.25 = **2.4 m³**
6. Q = 2.4 × (60 / 1.7) × 0.83 ≈ **70.3 m³/h**
7. שעות = 3000 / 70.3 ≈ 42.7 → 5.3 ימים → **6 ימים**
8. עלות = 6 × 8 × (300 + 60) = **17,280 ₪**
9. עלות ל-m³ = 17,280 / 3000 ≈ **5.76 ₪/m³**

## 📝 סוגי שאלות בדפים

- **דחפור**: עשרות מטרים, מהירות לכל הילוך, זמן החלפת הילוכים.
- **משאית**: קילומטרים, זמן **העמסה** + **פריקה**.
- סוג הקרקע נתון **בשם** → לקחת את אחוז התפיחה **מהטבלה**.
- עלות הכלי נתונה **ליום** → לא לכפול שוב ב-8.
- בפתרונות המרצה: קודם **ימים**, אחר כך **עלות**, ובסוף **עלות ל-m³**.

## ⚠️ טעויות נפוצות

- לשכוח **לחלק בתפיחה**.
- לערבב **שניות, דקות, שעות** באותה נוסחה.
- לשכוח **זמנים קבועים** (הילוכים, העמסה, פריקה).
- לשכוח את **המפעיל** בעלות.
- לא לעגל **ימים** למעלה.

## 🧠 לזכור

- **Q = (V כף / (1+תפיחה)) × 60/T × ניצולת**
- 1 km/h ≈ **16.7 m/min**
- המרצה מדגיש: **לשים לב ליחידות**.
