# 2. מספרים מכוונים וחוקי החשבון

> ⚡ **בקצרה:** סימנים **שווים** = **פלוס**. סימנים **שונים** = **מינוס**. **מינוס לפני סוגריים** הופך את כל הסימנים בפנים.

📄 בדף הנוסחאות: עמ' **1–2**

---

## 🌡️ הרעיון

- מדחום: **+5°** = 5 מעל האפס. **−5°** = 5 מתחת.
- **ערך מוחלט** = המרחק מאפס, בלי סימן.
- **|−7| = 7** וגם **|+7| = 7**

## ✖️ כפל וחילוק

- סימנים **שווים** → **+**: (−3)·(−4) = **+12**
- סימנים **שונים** → **−**: (−12) : (+3) = **−4**

## ➕ חיבור וחיסור

1. סימנים **שווים**: לחבר, ולשמור את הסימן. −6 − 23 = **−29**
2. סימנים **שונים**: לחסר, ולקחת את הסימן של **הגדול** (בלי סימן). −35 + 13 = **−22**

## 🔺 חזקה ושורש של מספר שלילי

- מעריך **זוגי** → **+**: (−2)² = **4**
- מעריך **אי-זוגי** → **−**: (−2)³ = **−8**
- ⚠️ בלי סוגריים זה אחרת: −2² = **−4** (המינוס בחוץ)
- שורש **זוגי** של שלילי → **לא מוגדר**: √(−4) = ❌
- שורש **אי-זוגי** של שלילי → **שלילי**: ∛(−8) = **−2**

## 🧺 סוגריים

- **פלוס** לפני סוגריים → הסימנים בפנים **לא משתנים**.
- **מינוס** לפני סוגריים → **כל** סימן בפנים **מתהפך**.

**דוגמה:** 10 − (3 − 5 + 2)

1. להפוך סימנים: 10 − 3 + 5 − 2
2. לחשב: **10**
3. בדיקה: בתוך הסוגריים יוצא 0. ו-10 − 0 = 10 ✓

## 📏 חוקי החשבון

| חוק | נוסחה | דוגמה |
|---|---|---|
| **חילוף** | a + b = b + a , a·b = b·a | 4 + 3 = 3 + 4 |
| **קיבוץ** | (a + b) + c = a + (b + c) | (5 + 2) + 8 = 5 + 10 |
| **פילוג** | a·(b + c) = a·b + a·c | 3·(4 + 5) = 12 + 15 = **27** |

- גם: **a − b = −(b − a)**. למשל 3 − 9 = −(9 − 3) = **−6**

## 🔢 סדר פעולות (רשות, טוב לדעת)

1. **סוגריים**
2. **חזקות** ושורשים
3. **כפל** וחילוק
4. **חיבור** וחיסור

## 🧠 לזכור

- סימנים שווים = **+**, שונים = **−**.
- **מינוס לפני סוגריים** = להפוך הכול.
- שלילי בחזקה **זוגית** = **חיובי**.
