# 21. פרבולה (פונקציה ריבועית)

> ⚡ **בקצרה:** **y = ax² + bx + c**. **a > 0** = "מחייכת" (נקודת **מינימום**). **a < 0** = "עצובה" (נקודת **מקסימום**). הקדקוד ב-**x = −b : 2a**.

📄 בדף הנוסחאות: עמ' **36–40** · בחוברת: עמ' **111–118**

---

## 🙂🙁 הצורה

- **a > 0** → **פרבולה ישרה** ∪ → יש **מינימום** (נקודה הכי נמוכה)
- **a < 0** → **פרבולה הפוכה** ∩ → יש **מקסימום** (נקודה הכי גבוהה)
- **a ≠ 0** תמיד (אחרת זה ישר)

## 📍 הקדקוד (נקודת קיצון)

- **x = −b : 2a**
- **y**: להציב את x בפונקציה (או: **y = c − b² : 4a**)

## ✂️ חיתוך עם הצירים

- עם ציר **y**: להציב **x = 0** → הנקודה **(0, c)**
- עם ציר **x**: להציב **y = 0** → לפתור **משוואה ריבועית** (פתק 17)

| Δ = b² − 4ac | חיתוך עם ציר x |
|---|---|
| **Δ > 0** | **2** נקודות |
| **Δ = 0** | **1** נקודה (הקדקוד נוגע בציר) |
| **Δ < 0** | **אין** חיתוך |

## ↗️↘️ עלייה וירידה

| | שמאלה מהקדקוד | ימינה מהקדקוד |
|---|---|---|
| **a > 0** ∪ | **יורדת** | **עולה** |
| **a < 0** ∩ | **עולה** | **יורדת** |

## ➕➖ חיובית ושלילית

- **חיובית** = הגרף **מעל** ציר x (y > 0)
- **שלילית** = הגרף **מתחת** לציר x (y < 0)
- נקודות החיתוך עם ציר x = **הגבולות**

## 🔢 דוגמה מלאה: y = x² − 4x + 3

```
  y
  |  \         /
  |   \       /
--+----*-----*------ x
  |    1\   /3
  |      \_/
  |     (2,-1)
```

1. **צורה**: a = 1 > 0 → ∪, מינימום
2. **קדקוד**: x = 4 : 2 = 2 → y = 4 − 8 + 3 = −1 → **(2, −1)**
3. **ציר y**: **(0, 3)**
4. **ציר x**: x² − 4x + 3 = 0 → x = 1, 3 → **(1, 0)**, **(3, 0)**
5. **יורדת** כש-x < 2, **עולה** כש-x > 2
6. **שלילית** כש-1 < x < 3
7. בדיקה: קדקוד **באמצע** בין 1 ל-3 ✓

## ❌ חיתוך פרבולה עם ישר

1. **להשוות**: הפרבולה = הישר.
2. להעביר הכול לצד אחד → **משוואה ריבועית**.
3. לפתור → x. להציב בישר → y.

## 🧠 לזכור

- סימן **a** קובע: ∪ (מינימום) או ∩ (מקסימום).
- קדקוד: **x = −b : 2a**.
- ציר x: **y = 0**. ציר y: **x = 0** → (0, c).
