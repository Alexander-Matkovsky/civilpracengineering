# 4. אחוזים

> ⚡ **בקצרה:** אחוז = **חלק ממאה**. 15% = **0.15**. מחיר **אחרי** = **לכפול**. מחיר **לפני** = **לחלק**.

📄 בדף הנוסחאות: עמ' **3–4** · בחוברת: עמ' **2–3**

---

## 🍕 הרעיון

- פיצה ב-**100** חתיכות. **30%** = 30 חתיכות.
- לכן **30% = 30/100 = 0.3**

## 🔁 המרות

- **אחוז → מספר**: לחלק ב-100. 30% = **0.3**
- **מספר → אחוז**: לכפול ב-100. 0.78 = **78%**

## 🎯 אחוז ממספר

**החלק = האחוז (כמספר עשרוני) · המספר**

- דוגמה: 20% מ-150 → 0.2 · 150 = **30**

## 🔍 מציאת המספר (כשיודעים חלק ממנו)

**המספר = החלק : האחוז (כמספר עשרוני)**

- דוגמה: 25% ממספר הם 40 → 40 : 0.25 = **160**
- בדיקה: 25% מ-160 = 40 ✓

## 📉📈 כמה אחוז הנחה / התייקרות?

**אחוז השינוי = (השינוי : המחיר המקורי) · 100**

- **השינוי** = גדול − קטן (ההפרש בין המחירים)
- **הנחה**: לחלק במחיר **הגדול** (המקורי)
- **התייקרות**: לחלק במחיר **הקטן** (המקורי)
- 💡 בשניהם: לחלק במחיר **לפני** השינוי

**דוגמאות:**

- ירד **מ-200 ל-150**: 50 : 200 · 100 = **25% הנחה**
- עלה **מ-80 ל-100**: 20 : 80 · 100 = **25% התייקרות**

## 💰 מחיר אחרי / לפני

| מה מחפשים | נוסחה | דוגמה (15%) |
|---|---|---|
| **אחרי הנחה** | לפני · (1 − 0.15) | 200 · 0.85 = **170** |
| **אחרי התייקרות** | לפני · (1 + 0.15) | 200 · 1.15 = **230** |
| **לפני הנחה** | אחרי : (1 − 0.15) | 170 : 0.85 = **200** |
| **לפני התייקרות** | אחרי : (1 + 0.15) | 230 : 1.15 = **200** |

## 🪄 טריק לזכירה

1. **הנחה** → **מינוס** (1 − האחוז)
2. **התייקרות** → **פלוס** (1 + האחוז)
3. מחפשים מחיר **אחרי** → **כפל**
4. מחפשים מחיר **לפני** → **חילוק**

## 🧠 לזכור

- אחוז → עשרוני: **לחלק ב-100**.
- אחוז שינוי: לחלק במחיר **המקורי**.
- אחרי = **כפל**, לפני = **חילוק**.
