# 11. דמיון משולשים

> ⚡ **בקצרה:** משולשים **דומים** = **אותה צורה, גודל אחר**. הזוויות **שוות**, והיחס בין הצלעות **קבוע**. כך מוצאים צלע חסרה.

📄 בדף הנוסחאות: עמ' **23** · בחוברת: עמ' **62–65**

---

## 📸 הרעיון

- תמונה בטלפון ואותה תמונה **מוגדלת** על מסך.
- הצורה **אותה צורה**. הכול גדל **פי אותו מספר**.
- זה **דמיון**. הסימן: **∽**

## 🔍 איך יודעים שמשולשים דומים?

- מספיק להראות **2 זוגות של זוויות שוות** (השלישית תהיה שווה לבד).
- בתרגילים זה בדרך כלל:
  1. **זווית משותפת** (אותה זווית לשני המשולשים)
  2. **+ זווית ישרה** בשניהם, **או** זוויות **מתאימות** (בגלל ישר מקביל)

```
             C
            /|
           / |
          E  |
         /|  |
        / |  |
       A--D--B
```

- משולש קטן **ADE** בתוך משולש גדול **ABC**.
- **∢A** משותפת. **∢D = ∢B = 90°**. לכן **ΔABC ∽ ΔADE**.

## 🧮 היחס

**AD : AB = DE : BC = AE : AC**

- צלע **קטנה** חלקי הצלע **המתאימה** בגדול. תמיד **באותו סדר**.
- צלעות מתאימות = צלעות שנמצאות **מול זוויות שוות**.

## 🔢 הדרך (5 צעדים)

1. להראות **2 זוויות שוות** → המשולשים דומים.
2. לכתוב את הדמיון **בסדר הנכון** (A עם A, D עם B...).
3. לכתוב יחס עם **שתי צלעות ידועות** ו**אחת חסרה**.
4. **כפל בהצלבה** ולחלק.
5. בדיקה: במשולש **הגדול** הצלע יצאה **גדולה יותר**?

**דוגמה:** במשולש הקטן: בסיס **3**, גובה **2**. במשולש הגדול: בסיס **9**. מה הגובה?

1. 2 : h = 3 : 9
2. 3 · h = 2 · 9 = 18
3. h = **6**
4. בדיקה: הכול גדל **פי 3** (3 נהיה 9, ו-2 נהיה 6) ✓

## 🧠 לזכור

- דומים = **זוויות שוות** + **יחס צלעות קבוע**.
- 2 זוגות זוויות שוות **מספיקים**.
- צלע קטנה / צלע גדולה **מתאימה**.
