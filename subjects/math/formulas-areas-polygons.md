# 9. שטחים והיקפים: משולשים ומרובעים

> ⚡ **בקצרה:** **היקף** = לחבר את **כל הצלעות** (ס"מ). **שטח** = כמה משבצות בפנים (סמ"ר). משולש = **בסיס · גובה : 2**.

📄 בדף הנוסחאות: עמ' **21–22** · בחוברת: עמ' **57–59**

---

## 🏡 הרעיון

- **היקף** = אורך **הגדר** מסביב לחצר. יחידות: **ס"מ**.
- **שטח** = כמה **מרצפות** מכסות את החצר. יחידות: **סמ"ר**.

## 🔤 הסימנים

- **A** = שטח · **P** = היקף
- **a, b, c** = צלעות · **h** = גובה (ב-90° לצלע)
- **k₁, k₂** = אלכסונים

## ⬜ מרובעים

| צורה | שטח A | היקף P | דוגמה |
|---|---|---|---|
| **ריבוע** | a² | 4a | a = 3 → A = **9**, P = **12** |
| **מלבן** | a · b | 2(a + b) | 5 על 3 → A = **15**, P = **16** |
| **מקבילית** | a · h | 2(a + b) | a = 8, h = 5 → A = **40** |
| **טרפז** | h · (a + b) : 2 | סכום 4 הצלעות | בסיסים 6, 10, גובה 4 → A = **32** |
| **מעוין** | k₁ · k₂ : 2 | 4a | אלכסונים 6, 8 → A = **24** |
| **דלתון** | k₁ · k₂ : 2 | 2(a + b) | אלכסונים 4, 10 → A = **20** |

- בטרפז: **a, b** = שני **הבסיסים** (המקבילים).
- ⚠️ בדף הנוסחאות כתוב למקבילית גם **k₁·k₂ : 2**. זה נכון **רק** כשהאלכסונים **מאונכים** (מעוין, ריבוע). למקבילית רגילה: **a · h**.

## 🔺 משולשים

| משולש | שטח A | היקף P |
|---|---|---|
| **כל משולש** | a · h : 2 | a + b + c |
| **ישר זווית** | ניצב · ניצב : 2 | a + b + c |
| **שווה צלעות** | a²·√3 : 4 ≈ **0.43·a²** | 3a |

- דוגמה: בסיס 10, גובה 4 → A = 10 · 4 : 2 = **20**
- שווה צלעות: הגובה **h ≈ 0.866·a**

## 🔄 הפוך: מחפשים צלע או גובה

- במשולש: **h = 2A : a**
- במקבילית: **h = A : a**
- דוגמה: משולש עם A = 30, בסיס 12 → h = 60 : 12 = **5**

## 🔗 חיבור לפיתגורס

- מעוין עם אלכסונים 6 ו-8: חצאי האלכסונים = 3 ו-4.
- הצלע = √(9 + 16) = **5** → P = 4 · 5 = **20**

## 🧠 לזכור

- היקף = **ס"מ**, שטח = **סמ"ר**.
- משולש = **בסיס · גובה : 2**.
- מעוין ודלתון = **אלכסון · אלכסון : 2**.
