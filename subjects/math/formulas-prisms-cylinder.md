# 18. מנסרות וגליל

> ⚡ **בקצרה:** גוף "**ישר**" (אותו בסיס למטה ולמעלה): **נפח = שטח בסיס · גובה**. **שטח פנים = מעטפת + 2 בסיסים**.

📄 בדף הנוסחאות: עמ' **28, 30** · בחוברת: עמ' **87–92, 98–99**

---

## 🎁 הרעיון

- קופסת נעליים. **המעטפת** = נייר העטיפה **מסביב** (בלי מכסה ותחתית).
- **שטח הפנים** = כל הנייר, **כולל** מכסה ותחתית.
- **הנפח** = כמה **נכנס** בפנים.

## 🔤 הסימנים (כמו בדף הנוסחאות)

- **S בסיס** = שטח הבסיס · **S פיאה** = שטח פאה צדדית
- **M** = שטח **מעטפת** = סכום הפאות הצדדיות (סמ"ר)
- **N** = שטח **פנים** = **M + 2·S בסיס** (סמ"ר)
- **V** = **נפח** = **S בסיס · h** (סמ"ק)
- **h** = גובה הגוף

## 🧊 קובייה (צלע a)

- **M = 4a²** · **N = 6a²** · **V = a³**
- דוגמה: a = 3 → N = 6 · 9 = **54**, V = **27**

## 📦 תיבה (בסיס a על b, גובה h)

- **S בסיס = a · b**
- **M = 2·(a·h + b·h)** (2 זוגות של פאות)
- **N = M + 2ab** · **V = a · b · h**
- דוגמה: 2 על 3, גובה 4:
  1. S בסיס = **6**
  2. M = 2 · (8 + 12) = **40**
  3. N = 40 + 12 = **52**
  4. V = 6 · 4 = **24**

## 🔺 מנסרה משולשת (בסיס = משולש שווה צלעות, צלע a)

- **S בסיס = a²·√3 : 4 ≈ 0.43·a²**
- **M = 3 · a · h** (3 פאות מלבניות)
- **N = M + 2·S בסיס** · **V = S בסיס · h**
- דוגמה: a = 10, h = 5 → S בסיס ≈ **43.3**, V ≈ 43.3 · 5 = **216.5**

## 🥫 גליל (רדיוס R, גובה h)

- **S בסיס = π·R²**
- **M = 2·π·R·h** (המעטפת פרושה = מלבן)
- **N = M + 2·π·R²** · **V = π·R²·h**
- דוגמה: R = 2, h = 5:
  1. S בסיס = 3.14 · 4 = **12.56**
  2. M = 2 · 3.14 · 2 · 5 = **62.8**
  3. N = 62.8 + 25.12 = **87.92**
  4. V = 12.56 · 5 = **62.8**

## 🔄 הפוך: מחפשים גובה

- **h = V : S בסיס**
- דוגמה: V = 60, S בסיס = 12 → h = **5**

## 🧠 לזכור

- נפח = **S בסיס · h**.
- שטח פנים = מעטפת + **2** בסיסים.
- שטח = **סמ"ר**, נפח = **סמ"ק**.
