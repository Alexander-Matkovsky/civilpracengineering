# 6. זוויות ומשולשים

> ⚡ **בקצרה:** במשולש: סכום הזוויות = **180°**. בין ישרים מקבילים: זוויות **מתאימות, מתחלפות, קודקודיות** = **שוות**. זוויות **צמודות** = **180°** ביחד.

📄 בדף הנוסחאות: עמ' **11, 13–15, 20**

---

## 📐 סוגי זוויות

| סוג | גודל |
|---|---|
| **חדה** | פחות מ-**90°** |
| **ישרה** | בדיוק **90°** |
| **קהה** | בין **90°** ל-**180°** |
| **שטוחה** | בדיוק **180°** (קו ישר) |
| גדולה מ-180° | בין **180°** ל-**360°** |

## 🛤️ שני ישרים מקבילים + ישר שחותך אותם

```
           \  t
        1   \   2
  L1 --------X--------
        4     \   3
               \
            5   \   6
  L2 ------------X------
            8     \   7
                   \
```

- **מתאימות** (אותו מקום בכל צומת): 1=5, 2=6, 3=7, 4=8 → **שוות**
- **מתחלפות** (בין הישרים, צדדים הפוכים): 3=5, 4=6 → **שוות**
- **קודקודיות** (ממול, באותו צומת): 1=3, 2=4 → **שוות**
- **צמודות** (אחת ליד השנייה על קו): 1+2 = **180°**

## 🔺 משולש

- סכום הזוויות = **180°**. תמיד.
- דוגמה: 50° + 60° + ? = 180° → **70°**

| סוג | מה מיוחד |
|---|---|
| **פשוט** | אין צלעות שוות, אין זוויות שוות |
| **שווה שוקיים** | **2** צלעות שוות → **זוויות הבסיס שוות** |
| **שווה צלעות** | **3** צלעות שוות → כל זווית **60°** |

- בשווה שוקיים ובשווה צלעות: **הגובה לבסיס** חוצה את הבסיס **לשניים** ואת זווית הראש **לשניים**.

## 🚪 זווית חיצונית

**γ = α + β**

- **γ** = זווית **מחוץ** למשולש (המשך של צלע)
- **α, β** = שתי הזוויות **הפנימיות הרחוקות** ממנה
- דוגמה: α = 40°, β = 70° → γ = **110°**
- בדיקה: הזווית הפנימית השלישית = 70°, ו-180° − 70° = 110° ✓

## 📏 קווים במשולש

- **גובה**: קו שיוצר **90°** עם הצלע.
- **תיכון**: מקודקוד אל **אמצע** הצלע שמולו. מחלק לשני משולשים **שווי שטח**.
- **חוצה זווית**: מחלק זווית לשני חלקים **שווים** (מופיע הרבה בחוברת).
- **יתר**: הצלע **מול הזווית הישרה**, הכי ארוכה.

## 🧠 לזכור

- משולש = **180°**. מרובע = **360°**.
- מתאימות, מתחלפות, קודקודיות = **שוות**. צמודות = **180°**.
- זווית חיצונית = **סכום שתי הרחוקות**.
