# 10. שטחים והיקפים: עיגול

> ⚡ **בקצרה:** שטח עיגול = **π·R²**. היקף = **2·π·R**. בקורס: **π = 3.14**. קשת וגזרה = **חלק** מהעיגול לפי הזווית.

📄 בדף הנוסחאות: עמ' **22** · בחוברת: עמ' **59–61**

---

## 🍕 הרעיון

- פיצה עגולה. **השטח** = כמה פיצה יש. **ההיקף** = אורך **הקראסט**.
- **R** = רדיוס (מהמרכז לקצה). **D** = קוטר = **2R**.

## ⭕ עיגול שלם

- **A = π · R²** (שטח, סמ"ר)
- **P = 2 · π · R** = π · D (היקף, ס"מ)
- דוגמה: R = 5 → A = 3.14 · 25 = **78.5**. P = 2 · 3.14 · 5 = **31.4**

## 🌗 חצי עיגול ורבע עיגול

| צורה | שטח | היקף |
|---|---|---|
| **חצי** | π·R² : 2 | R · (π + 2) |
| **רבע** | π·R² : 4 | R · (π/2 + 2) |

- ⚠️ בהיקף **מוסיפים את הקווים הישרים**: חצי = קשת + **קוטר**. רבע = קשת + **2 רדיוסים**.
- דוגמה: חצי עיגול, R = 5 → A = **39.25**. P = 5 · 5.14 = **25.7**

## 🍩 טבעת

- **A = π · (R² − r²)**
- **R** = רדיוס **חיצוני**, **r** = רדיוס **פנימי**
- דוגמה: R = 5, r = 3 → A = 3.14 · (25 − 9) = 3.14 · 16 = **50.24**

## 🌈 קשת (אורך)

- **L = π · R · α : 180**
- **α** = הזווית המרכזית (במעלות)
- דוגמה: R = 10, α = 90° → L = 3.14 · 10 · 90 : 180 = **15.7**

## 🍰 גזרה (שטח)

- **A = π · R² · α : 360**
- דוגמה: R = 10, α = 90° → A = 3.14 · 100 · 90 : 360 = **78.5**
- 💡 בדיקה: 90° = **רבע** עיגול. ורבע מ-314 = 78.5 ✓

## 🔄 הפוך: מחפשים רדיוס

- מהשטח: **R = √(A : π)**
- מההיקף: **R = P : (2π)**
- דוגמה: A = 314 → R = √(314 : 3.14) = √100 = **10**

## 🧠 לזכור

- **A = πR²**, **P = 2πR**, **π = 3.14**.
- קשת: לחלק ב-**180**. גזרה: לחלק ב-**360**.
- חצי/רבע עיגול: בהיקף לא לשכוח **את הקווים הישרים**.
