# 13. משפט הסינוסים והקוסינוסים

> ⚡ **בקצרה:** למשולש **בלי** זווית ישרה. יש **צלע + הזווית שמולה**? → **סינוסים**. אין זוג כזה? → **קוסינוסים**.

📄 בדף הנוסחאות: עמ' **27** · בחוברת: עמ' **76–85**

---

## 🔺 הסימנים

```
          B
         / \
      c /   \ a
       /     \
      A-------C
          b
```

- צלע **a** מול זווית **α** (ב-A)
- צלע **b** מול זווית **β** (ב-B)
- צלע **c** מול זווית **γ** (ב-C)
- 💡 כל צלע נקראת לפי **הזווית שמולה**. לבדוק בשרטוט: a לא נוגעת ב-A.

## 1️⃣ משפט הסינוסים

**a : sin α = b : sin β = c : sin γ = 2R**

- **R** = רדיוס **המעגל החוסם** (המעגל שעובר דרך 3 הקודקודים)
- מתי? יש **זוג** (צלע + הזווית מולה) + עוד נתון אחד.

**דוגמה:** a = 10, α = 30°, β = 45°. מה b?

1. b = a · sin β : sin α
2. b = 10 · 0.707 : 0.5 = **14.14**
3. בונוס: 2R = 10 : 0.5 = 20 → R = **10**

- ⚠️ מוצאים **זווית** והיא אמורה להיות **קהה**? המחשבון נותן חדה. אז: **180° − התוצאה**.

## 2️⃣ משפט הקוסינוסים

**c² = a² + b² − 2·a·b·cos γ**

- **γ** = הזווית **בין** a ל-b
- מתי? **2 צלעות + הזווית שביניהן** → צלע שלישית.
- או: **3 צלעות** → זווית.

**דוגמה (צלע):** a = 5, b = 8, γ = 60°

1. c² = 25 + 64 − 2 · 5 · 8 · 0.5
2. c² = 89 − 40 = 49
3. c = **7**

**דוגמה (זווית):** 3 צלעות: a = 5, b = 8, c = 7

1. γ = shift cos((c² − a² − b²) : (−2ab))
2. γ = shift cos((49 − 25 − 64) : (−80)) = shift cos(0.5)
3. γ = **60°** ✓ (כמו בדוגמה הקודמת)

## 🔢 הדרך: איזה משפט?

1. לסמן מה **נתון** ומה **מחפשים**.
2. יש **צלע + הזווית שמולה**? → **סינוסים**.
3. אין? → **קוסינוסים**.
4. חסרה זווית שלישית? **180° פחות השתיים**.

## 🧠 לזכור

- **זוג** (צלע מול זווית) = **סינוסים**.
- 2 צלעות + זווית **ביניהן**, או 3 צלעות = **קוסינוסים**.
- סכום הזוויות = **180°**.
