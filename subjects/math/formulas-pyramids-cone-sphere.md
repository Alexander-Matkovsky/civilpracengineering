# 19. פירמידות, חרוט וכדור

> ⚡ **בקצרה:** גוף "**מחודד**": **נפח = S בסיס · h : 3**. **שטח פנים = מעטפת + בסיס אחד** (יש רק בסיס **אחד**).

📄 בדף הנוסחאות: עמ' **29–30** · בחוברת: עמ' **93–97, 100–103**

---

## 🍦 הרעיון

- גביע גלידה (חרוט) מכיל **שליש** מכוס (גליל) עם אותו בסיס ואותו גובה.
- לכן מחלקים ב-**3**.

## 📏 שני גבהים בפירמידה (לא להתבלבל!)

```
        S
       /|
  h1  / |  h
     /  |
    K---O
     a/2
```

- **h** (או SO) = **גובה הפירמידה**: מהקודקוד S ישר למטה, למרכז הבסיס O.
- **h1** (או SK) = **גובה הפאה**: מ-S לאמצע צלע הבסיס K.
- משולש **SOK** ישר זווית → **פיתגורס**: **h1² = h² + OK²**
- בבסיס ריבועי: **OK = a : 2**

## 🔺 פירמידה ריבועית (צלע בסיס a)

- **S בסיס = a²** · **S פיאה = a · h1 : 2**
- **M = 4 · S פיאה** · **N = M + a²**
- **V = a² · h : 3**

**דוגמה:** a = 6, h = 4

1. OK = 3 → h1 = √(16 + 9) = **5**
2. S פיאה = 6 · 5 : 2 = **15** → M = **60**
3. N = 60 + 36 = **96**
4. V = 36 · 4 : 3 = **48**

- בסיס **מלבני**: יש **2 סוגי** פאות → M = 2 · (S פיאה 1 + S פיאה 2).
- בסיס **משולש שווה צלעות**: S בסיס ≈ 0.43·a², M = 3 · S פיאה.

## 🍦 חרוט (רדיוס R, גובה h, קו יוצר l)

- **l** = הקו מהקודקוד לשפת הבסיס (**l² = R² + h²**)
- **S בסיס = π·R²** · **M = π·R·l**
- **N = M + π·R²** · **V = π·R²·h : 3**

**דוגמה:** R = 3, h = 4

1. l = √(9 + 16) = **5**
2. M = 3.14 · 3 · 5 = **47.1**
3. N = 47.1 + 28.26 = **75.36**
4. V = 3.14 · 9 · 4 : 3 = **37.68**

## ⚽ כדור (רדיוס R)

- **N = 4·π·R²** (שטח פנים)
- **V = 4·π·R³ : 3** ≈ 4.19·R³
- אין לכדור בסיס ואין מעטפת.
- דוגמה: R = 3 → N = 4 · 3.14 · 9 = **113.04**, V = 4 · 3.14 · 27 : 3 = **113.04**

## 🧠 לזכור

- מחודד: נפח **: 3**, ו**בסיס אחד** בשטח הפנים.
- **h** (גובה הגוף) ≠ **h1** (גובה הפאה). מחברים ביניהם **בפיתגורס**.
- כדור: **N = 4πR²**, **V = 4πR³ : 3**.
