# 8. משפט פיתגורס

> ⚡ **בקצרה:** במשולש **ישר זווית**: **A² + B² = C²**. C = **היתר** (הצלע הכי ארוכה, מול הזווית הישרה).

📄 בדף הנוסחאות: עמ' **15, 20** · בחוברת: עמ' **53–56**

---

## 🪜 הרעיון

- סולם נשען על קיר. הקיר והרצפה = **זווית ישרה**.
- יודעים את גובה הקיר ואת המרחק מהקיר? אפשר לחשב את **אורך הסולם**.

## 🧮 הנוסחה

**A² + B² = C²**

```
    |\
    | \
  A |  \  C
    |   \
    |____\
       B
```

- **A, B** = **ניצבים** (הצלעות שיוצרות את ה-90°)
- **C** = **יתר** (מול ה-90°)
- מחפשים **יתר**: **C = √(A² + B²)**
- מחפשים **ניצב**: **A = √(C² − B²)**

## 🔢 הדרך (4 צעדים)

1. למצוא את **הזווית הישרה**.
2. **היתר** = הצלע שמולה.
3. מחפשים יתר → **לחבר** ריבועים. מחפשים ניצב → **לחסר** (גדול פחות קטן).
4. **שורש**. בדיקה: היתר יצא **הכי ארוך**?

**דוגמה 1 (יתר):** A = 6, B = 8

1. C = √(36 + 64)
2. C = √100 = **10** ✓ (10 הכי ארוך)

**דוגמה 2 (ניצב):** C = 13, A = 5

1. B = √(169 − 25)
2. B = √144 = **12** ✓

## ⭐ משולשים ישרי זווית מיוחדים

| משולש | יחס הצלעות |
|---|---|
| **45°-45°-90°** (שווה שוקיים) | 1 : 1 : √2 (≈ **1.41**) |
| **30°-60°-90°** (בדף: "משולש הזהב") | 1 : √3 : 2 |

- ב-30°-60°-90°: הניצב **מול 30°** = **חצי מהיתר**.
- דוגמה: יתר = 10 → הניצב מול 30° = **5**

## 🎲 "מידות אחידות" (מספרים שלמים)

- **3, 4, 5** · **5, 12, 13** · **8, 15, 17**
- גם כפולות שלהם: 6, 8, 10 ✓

## 🧠 לזכור

- **A² + B² = C²**. רק במשולש **ישר זווית**.
- יתר → **חיבור**. ניצב → **חיסור**. בסוף **שורש**.
- היתר תמיד **הכי ארוך**.
