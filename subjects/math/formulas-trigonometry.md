# 12. טריגונומטריה (משולש ישר זווית)

> ⚡ **בקצרה:** **sin = מול : יתר**. **cos = ליד : יתר**. **tan = מול : ליד**. מחפשים **זווית**? **SHIFT** + הפונקציה.

📄 בדף הנוסחאות: עמ' **24** (עמ' 25–27: הרחבה) · בחוברת: עמ' **67–75**

---

## 🏔️ הרעיון

- פיתגורס: יודעים **2 צלעות** → צלע שלישית.
- טריגונומטריה: יודעים **צלע + זווית** → עוד צלע. או **2 צלעות** → זווית.

## 🏷️ שמות הצלעות (תמיד לפי הזווית α)

```
        |\
        | \
  A     |  \   C
 (opp)  |   \ (hyp)
        |____\ alpha
          B
        (adj)
```

- **A** = ניצב **מול** α
- **B** = ניצב **ליד** α
- **C** = **יתר** (מול ה-90°)

## 🧮 שלוש הנוסחאות

| פונקציה | נוסחה | מוצאים זווית |
|---|---|---|
| **sin α** | מול : יתר = A : C | α = shift sin(A : C) |
| **cos α** | ליד : יתר = B : C | α = shift cos(B : C) |
| **tan α** | מול : ליד = A : B | α = shift tan(A : B) |

- שתי הזוויות החדות: **α + β = 90°**
- sin ו-cos תמיד **בין −1 ל-1**

## 🔢 הדרך (5 צעדים)

1. לסמן את **הזווית** שעובדים איתה.
2. לתת שם לכל צלע: **מול / ליד / יתר**.
3. לבחור פונקציה שיש בה **הנתון** וגם **מה שמחפשים**.
4. להציב ולפתור.
5. בדיקה: **היתר הכי ארוך**?

**דוגמה 1 (צלע):** יתר = 10, α = 30°. מה הניצב מול α?

1. sin 30° = A : 10
2. A = 10 · 0.5 = **5** ✓ (קטן מ-10)

**דוגמה 2 (זווית):** מול = 3, ליד = 4. מה α?

1. tan α = 3 : 4 = 0.75
2. α = shift tan(0.75) ≈ **36.87°**

## ⭐ זוויות שימושיות

| α | 30° | 45° | 60° |
|---|---|---|---|
| **sin** | 0.5 | 0.707 | 0.866 |
| **cos** | 0.866 | 0.707 | 0.5 |
| **tan** | 0.577 | 1 | 1.732 |

## 🖩 טיפ למחשבון

- לוודא שהמחשבון **במעלות** (DEG). בדרך כלל רואים **D** בראש המסך.
- **shift sin** = הפעולה ההפוכה: מקבלים **זווית** מתוך מספר.

## 📐 רדיאנים (רשות)

- מעלות → רדיאנים: **α · π : 180**
- רדיאנים → מעלות: **α · 180 : π**

## 🧠 לזכור

- **sin = מול/יתר**, **cos = ליד/יתר**, **tan = מול/ליד**.
- זווית חסרה? **shift** + הפונקציה.
- מחשבון במצב **מעלות**.
