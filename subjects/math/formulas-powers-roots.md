# 5. חזקות ושורשים

> ⚡ **בקצרה:** כפל של **אותו בסיס** = **לחבר** מעריכים. חילוק = **לחסר**. חזקה של חזקה = **לכפול**. שורש = **חזקה בשבר**.

📄 בדף הנוסחאות: עמ' **5–6** · בחוברת: עמ' **7, 9**

---

## 🧱 המושגים

- ב-**2³**: ה-**2** = **בסיס**. ה-**3** = **מעריך**.
- **2³ = 2 · 2 · 2 = 8** (הבסיס כפול עצמו, 3 פעמים)

## ⚙️ חוקי החזקות

| חוק | נוסחה | דוגמה |
|---|---|---|
| **כפל** (אותו בסיס) | aᵐ · aⁿ = aᵐ⁺ⁿ | 2³ · 2² = 2⁵ = **32** |
| **חילוק** (אותו בסיס) | aᵐ : aⁿ = aᵐ⁻ⁿ | x⁷ : x³ = **x⁴** |
| **חזקה של חזקה** | (aᵐ)ⁿ = aᵐ·ⁿ | (x²)³ = **x⁶** |
| **אפס** | a⁰ = 1 | 5⁰ = **1** |
| **אחד** | a¹ = a | 7¹ = **7** |
| **מכפלה** | aⁿ · bⁿ = (a·b)ⁿ | (2x)³ = **8x³** |
| **מנה** | aⁿ : bⁿ = (a/b)ⁿ | (x/3)² = **x²/9** |
| **מעריך שלילי** | a⁻ⁿ = 1/aⁿ | 2⁻³ = **1/8** |

## √ חוקי השורשים

| חוק | נוסחה | דוגמה |
|---|---|---|
| **כפל** | ⁿ√a · ⁿ√b = ⁿ√(a·b) | √2 · √8 = √16 = **4** |
| **חילוק** | ⁿ√a : ⁿ√b = ⁿ√(a/b) | √50 : √2 = √25 = **5** |
| **שורש של שורש** | ᵐ√(ⁿ√a) = ᵐ·ⁿ√a | √(√16) = ⁴√16 = **2** |
| **שורש = שבר** | ⁿ√(aᵐ) = a^(m/n) | ∛(8²) = 8^(2/3) = **4** |

- **מעריך השורש** = המספר הקטן ליד הסימן. ב-√ רגיל הוא **2**.

## 🔢 הדרך לפשט ביטוי

1. להפוך כל **שורש** לחזקה בשבר (√x = x^(1/2)).
2. לסדר לפי **בסיס** (כל ה-x ביחד, כל ה-y ביחד).
3. להפעיל את החוקים: **לחבר / לחסר / לכפול** מעריכים.
4. בדיקה: להציב מספר קטן (x = 2) בהתחלה ובסוף. צריך לצאת **אותו דבר**.

## 📋 חזקות שימושיות (רשות)

- בעמ' **5** בדף הנוסחאות יש טבלה מוכנה.
- כדאי להכיר: 2¹⁰ = **1024**, 12² = **144**, 15² = **225**, 25² = **625**

## 🧠 לזכור

- כפל = **חיבור** מעריכים. חילוק = **חיסור**.
- (aᵐ)ⁿ = **כפל** מעריכים.
- שורש = חזקה **בשבר**. a⁰ = **1**.
