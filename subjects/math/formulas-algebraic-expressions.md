# 14. תבניות אלגבריות וכפל מקוצר

> ⚡ **בקצרה:** מחברים רק **איברים דומים** (אותה אות, אותה חזקה). כופלים **כל איבר בכל איבר**. **(a + b)² = a² + 2ab + b²**, לא רק a² + b².

📄 בדף הנוסחאות: עמ' **7** · בחוברת: עמ' **12–24**

---

## 🍎 הרעיון

- 3 תפוחים + 2 תפוחים = **5 תפוחים**.
- 3 תפוחים + 2 בננות = **לא מתחברים**.
- באלגברה: **3x + 2x = 5x**, אבל **3x + 2y** נשאר כמו שהוא.

## 🔤 מושגים

- **מקדם** = המספר שלפני האות. ב-**7x** המקדם **7**.
- **חד איבר** = בלי + או −. למשל **4x²**.
- **רב איבר** = יש + או −. למשל **x² + 2x − 5**.

## 1️⃣ כינוס איברים דומים

- **דומים** = אותן אותיות **עם אותן חזקות**.
- מחברים את **המקדמים**. האות **לא משתנה**.
- דוגמה: 2x² + 5x² − 3x = **7x² − 3x**

## 2️⃣ כפל חד איבר בחד איבר

1. לכפול את **המספרים**.
2. אותה אות? **לחבר את החזקות**.
- דוגמה: 3x² · 4x³ = **12x⁵**

## 3️⃣ כפל חד איבר ברב איבר (פילוג)

- כל איבר בסוגריים **מקבל כפל**.
- דוגמה: 2x · (x − 5) = **2x² − 10x**

## 4️⃣ כפל רב איבר ברב איבר

- **כל** איבר מהסוגריים הראשונים כפול **כל** איבר מהשניים.
- דוגמה: (x + 2)(x + 3)
  1. x·x + x·3 + 2·x + 2·3
  2. x² + 3x + 2x + 6
  3. **x² + 5x + 6**

## ⚡ נוסחאות הכפל המקוצר

| נוסחה | דוגמה |
|---|---|
| **(a + b)² = a² + 2ab + b²** | (x + 4)² = x² + 8x + 16 |
| **(a − b)² = a² − 2ab + b²** | (x − 3)² = x² − 6x + 9 |
| **(a + b)(a − b) = a² − b²** | (x + 5)(x − 5) = x² − 25 |

- רשות (גם בדף): (a + b)³ = a³ + 3a²b + 3ab² + b³
- רשות: (a − b)³ = a³ − 3a²b + 3ab² − b³
- רשות: (a + b + c)² = a² + b² + c² + 2ab + 2bc + 2ac

## ⚠️ הטעות הכי נפוצה

- **(x + 4)² ≠ x² + 16**. שוכחים את **האיבר האמצעי 2ab**.
- בדיקה עם x = 1: (1 + 4)² = **25**. ו-1 + 8 + 16 = **25** ✓

## 🧠 לזכור

- מחברים רק **דומים**.
- כפל: מספרים **בכפל**, חזקות **בחיבור**.
- בריבוע של סכום יש **איבר אמצעי: 2ab**.
