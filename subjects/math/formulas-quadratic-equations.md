# 17. משוואות ריבועיות

> ⚡ **בקצרה:** להביא ל-**ax² + bx + c = 0**. להציב ב**נוסחת השורשים**. בדרך כלל יש **2 פתרונות**.

📄 בדף הנוסחאות: עמ' **10** (ו-Δ בעמ' 36) · בחוברת: עמ' **46–51**

---

## 🔤 הצורה

**ax² + bx + c = 0** (כש-a ≠ 0)

- **a** = המקדם של **x²**
- **b** = המקדם של **x**
- **c** = המספר **החופשי** (בלי x)

## 🧮 נוסחת השורשים

**x₁,₂ = (−b ± √(b² − 4ac)) : 2a**

- **±** = פעם עם **פלוס** (x₁), פעם עם **מינוס** (x₂).

## 🔢 הדרך (5 צעדים)

1. להעביר הכול לצד אחד. בצד השני: **0**.
2. לרשום **a, b, c** (עם הסימנים!).
3. לחשב **Δ = b² − 4ac** (מה שבתוך השורש).
4. להציב בנוסחה: פעם **+**, פעם **−**.
5. בדיקה: להציב פתרון במשוואה. יוצא **0**?

**דוגמה:** x² − 5x + 6 = 0

1. a = 1, b = −5, c = 6
2. Δ = 25 − 24 = **1**
3. x = (5 ± 1) : 2
4. x₁ = **3**, x₂ = **2**
5. בדיקה: 9 − 15 + 6 = 0 ✓

## 🚦 כמה פתרונות? (Δ)

| Δ | פתרונות |
|---|---|
| **Δ > 0** | **2** פתרונות |
| **Δ = 0** | **1** פתרון |
| **Δ < 0** | **אין** פתרון (שורש של שלילי) |

## ✂️ קיצורי דרך (משוואה חסרה)

| צורה | פתרון | דוגמה |
|---|---|---|
| **ax² + c = 0** (אין b) | x = ±√(−c : a) | x² − 16 = 0 → x = **±4** |
| **ax² + bx = 0** (אין c) | x₁ = 0 , x₂ = −b : a | 2x² − 6x = 0 → x = **0, 3** |

## ⚠️ טעויות סימן

- b שלילי? אז **−b חיובי**. (b = −5 → −b = **5**)
- **b² תמיד חיובי**. במחשבון לכתוב **(−5)²**, עם סוגריים.

## 2️⃣ מערכת עם שני נעלמים (אחת ריבועית)

1. מהמשוואה **הפשוטה** לבודד x או y.
2. להציב בריבועית → משוואה ריבועית **בנעלם אחד**.
3. לפתור (בדרך כלל **2 פתרונות**).
4. לכל פתרון: למצוא את הנעלם השני → **2 זוגות**.

**דוגמה:** x + y = 5 , x · y = 6

1. y = 5 − x
2. x(5 − x) = 6 → x² − 5x + 6 = 0
3. x = 2 או x = 3
4. הזוגות: **(2, 3)** ו-**(3, 2)**

## 🧠 לזכור

- קודם **= 0**, אחר כך a, b, c.
- **Δ** קובע כמה פתרונות.
- **±** → שני פתרונות.
