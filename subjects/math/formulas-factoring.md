# 15. פירוק לגורמים

> ⚡ **בקצרה:** פירוק = **ההפך מפתיחת סוגריים**. הופכים חיבור ל**כפל**. תמיד מתחילים ב**גורם משותף**.

📄 בדף הנוסחאות: עמ' **7–8** · בחוברת: עמ' **25–35**

---

## 🧩 הרעיון

- פתיחת סוגריים: 3(x + 2) → 3x + 6
- פירוק: 3x + 6 → **3(x + 2)**
- בדיקה תמיד: **לפתוח בחזרה** ולקבל את מה שהיה.

## 1️⃣ הוצאת גורם משותף

- מה **מופיע בכל האיברים**? מספר, אות, או שניהם.
- דוגמה: 6x² + 9x = **3x(2x + 3)**
- לאות: מוציאים את **החזקה הקטנה** שמופיעה.

## 2️⃣ פירוק לפי קבוצות (4 איברים)

1. לחלק ל-**2 זוגות**.
2. מכל זוג להוציא **גורם משותף**.
3. נשארים **אותם סוגריים**? להוציא אותם.
- דוגמה: x² + 3x + 2x + 6
  1. x(x + 3) + 2(x + 3)
  2. **(x + 3)(x + 2)**

## 3️⃣ לפי נוסחאות הכפל המקוצר (הפוך)

| מזהים | מפרקים |
|---|---|
| a² − b² (הפרש ריבועים) | **(a − b)(a + b)** |
| a² + 2ab + b² | **(a + b)²** |
| a² − 2ab + b² | **(a − b)²** |

- דוגמה: x² − 49 = **(x − 7)(x + 7)**
- דוגמה: x² + 10x + 25 = **(x + 5)²** (כי 2 · x · 5 = 10x ✓)
- ⚠️ **a² + b²** (סכום ריבועים) → **אין פירוק**.

## 4️⃣ טרינום ריבועי: ax² + bx + c

1. למצוא **2 מספרים**: **סכום = b**, **מכפלה = a·c**.
2. לפצל את האיבר האמצעי לפיהם.
3. לפרק **לפי קבוצות**.

**דוגמה (a = 1):** x² − x − 12

1. סכום −1, מכפלה −12 → **3 ו-(−4)**
2. **(x + 3)(x − 4)**

**דוגמה (a ≠ 1):** 2x² + 7x + 3

1. סכום 7, מכפלה 2 · 3 = 6 → **6 ו-1**
2. 2x² + 6x + x + 3
3. 2x(x + 3) + 1(x + 3) = **(x + 3)(2x + 1)**

## 5️⃣ פירוק משולב: סדר העבודה

1. **גורם משותף** (תמיד ראשון!)
2. 4 איברים? **קבוצות**
3. 2 איברים עם מינוס? **הפרש ריבועים**
4. 3 איברים? **נוסחה** או **טרינום**
5. בדיקה: **לפתוח סוגריים** בחזרה

**דוגמה:** 3x² − 12

1. 3(x² − 4)
2. **3(x − 2)(x + 2)**

## 🧠 לזכור

- **גורם משותף** קודם.
- טרינום: **סכום = b**, **מכפלה = a·c**.
- בדיקה: **לפתוח סוגריים**.
