# 20. פונקציה קווית (ישר)

> ⚡ **בקצרה:** ישר = **y = a·x + b**. **a** = **שיפוע** (כמה תלול). **b** = איפה הישר **חותך את ציר y**.

📄 בדף הנוסחאות: עמ' **31–35** · בחוברת: עמ' **105–110**

---

## 🗺️ מערכת הצירים

```
          y
          |
     2    |    1
   (-,+)  |  (+,+)
  --------+--------- x
     3    |    4
   (-,-)  |  (+,-)
          |
```

- **x** = ציר **אופקי**, **y** = ציר **אנכי**
- **(0, 0)** = **ראשית הצירים**
- נקודה נכתבת **(x, y)**: קודם **ימינה/שמאלה**, אחר כך **למעלה/למטה**

## 📈 הישר y = a·x + b

- **a > 0** → ישר **עולה** ↗
- **a < 0** → ישר **יורד** ↘
- **a = 0** → ישר **אופקי**: **y = b** (מקביל לציר x)
- ישר **אנכי**: **x = מספר** (מקביל לציר y)
- **b = 0** → **y = a·x**, עובר **דרך (0, 0)**

## 🧮 שיפוע משתי נקודות

**a = (y₂ − y₁) : (x₂ − x₁)**

- דוגמה: (1, 2) ו-(3, 8) → a = (8 − 2) : (3 − 1) = 6 : 2 = **3**

## ✏️ משוואת ישר (שיפוע + נקודה)

**y − y₁ = a · (x − x₁)**

- **(x₁, y₁)** = נקודה **על הישר**
- דוגמה: a = 3, נקודה (1, 2):
  1. y − 2 = 3(x − 1)
  2. y − 2 = 3x − 3
  3. **y = 3x − 1**
  4. בדיקה עם (3, 8): 3 · 3 − 1 = 8 ✓

## ✂️ חיתוך עם הצירים

- עם ציר **x**: להציב **y = 0**
- עם ציר **y**: להציב **x = 0**
- דוגמה: y = 2x − 6
  1. ציר x: 0 = 2x − 6 → x = 3 → **(3, 0)**
  2. ציר y: y = 0 − 6 → **(0, −6)**

## ❌ נקודת מפגש של 2 ישרים

1. **להשוות**: y של ישר 1 = y של ישר 2 → למצוא **x**.
2. **להציב** את x באחד הישרים → למצוא **y**.

- דוגמה: y = x + 1 ו-y = −x + 5
  1. x + 1 = −x + 5 → 2x = 4 → x = **2**
  2. y = 2 + 1 = **3** → נקודה **(2, 3)**

## 🧠 לזכור

- **a** = שיפוע, **b** = חיתוך עם ציר y.
- שיפוע = **הפרש y : הפרש x**.
- חיתוך עם ציר x: **y = 0**. עם ציר y: **x = 0**.
