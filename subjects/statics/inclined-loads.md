# 5. כוחות אופקיים ובאלכסון על קורה

> ⚡ **בקצרה:** כוח באלכסון → **לפרק** ל-**Fx** ו-**Fy**. **Fy** נכנס ל-ΣFy ול-ΣM. **Fx** נכנס **רק** ל-ΣFx, ורק **הסמך הנייח** (או ריתום) מחזיק אותו.

---

## 🛒 הרעיון

- לדחוף עגלה **באלכסון**: חלק מהכוח **דוחף קדימה**, חלק **לוחץ למטה**.
- על קורה זה אותו דבר: **Fx** = לאורך הקורה, **Fy** = ניצב לקורה.

## 📐 לפרק (תזכורת מפתק 1)

- הזווית α נמדדת **מהקורה** (מהאופק):
  - **Fx = F · cos α**
  - **Fy = F · sin α**
- הזווית נמדדת **מהאנך**? → להחליף: Fx עם **sin**, Fy עם **cos**.
- 💡 טריק: הרכיב **שצמוד לזווית** = **cos**.
- הכיוון לפי החץ: חץ למטה-ימינה → Fx **ימינה**, Fy **למטה**.

## 0️⃣ למה Fx לא נכנס ל-ΣM?

- Fx פועל **לאורך הקורה** עצמה.
- כל נקודה על הקורה נמצאת **על הקו שלו** → d = 0 → **מומנט 0**.
- אז ב-ΣM סביב נקודה על הקורה: **רק Fy**.

## 🏗️ מי מחזיק כוח אופקי?

- סמך **נייד** → **לא** (רק ניצב למשטח).
- סמך **נייח** → **כן**: Ax.
- **ריתום** → **כן**: Ax.
- לכן **ΣFx = 0** נותן את **Ax** ישר.
- כוח **אופקי רגיל** (בלי זווית)? אותו דבר: נכנס רק ל-ΣFx.

## 🧩 דוגמה, צעד אחר צעד

קורה **5 m**. נייח ב-A, נייד ב-B. כוח **F = 10 kN** ב-**3 m** מ-A, ב-**30°** לקורה, **למטה-ימינה**.

```
          F = 10 kN
           \
            \
             \ 30 deg
  A===========+=========B
  ^                     ^
                        o
  |<--- 3 m ->|<- 2 m ->|
```

1. **לפרק:**
   - Fx = 10 · cos30° ≈ **8.66 kN** → ימינה
   - Fy = 10 · sin30° = **5 kN** → למטה
2. **ΣM סביב A = 0:**
   - Fy למטה, **מימין** ל-A → ↻ → **+5 · 3 = +15**
   - Fx לאורך הקורה → **0**
   - By למעלה, **מימין** ל-A → ↺ → **−By · 5**
   - 15 − 5·By = 0 → **By = 3 kN** ✅
3. **ΣFy = 0:** Ay + 3 − 5 = 0 → **Ay = 2 kN** ✅
4. **ΣFx = 0** (ימינה = פלוס): Ax + 8.66 = 0 → **Ax = −8.66 kN** → בפועל **שמאלה** ✅
5. **בדיקה, ΣM סביב B:**
   - Ay למעלה, **משמאל** ל-B → ↻ → **+2 · 5 = +10**
   - Fy למטה, **משמאל** ל-B → ↺ → **−5 · 2 = −10**
   - 10 − 10 = **0** ✅

> 💡 F דוחף ימינה → הסמך הנייח **מושך שמאלה**. הגיוני.

## ⚠️ טעויות נפוצות

- **sin ו-cos הפוכים** (לבדוק: הזווית מהקורה או מהאנך?).
- להכניס את **Fx** ל-ΣM.
- לתת לסמך **הנייד** תגובה אופקית.
- לשכוח לסמן בשרטוט את **הכיוון האמיתי** של תגובה שיצאה שלילית.

## 🧠 לזכור

- לפרק: **Fx = F·cosα**, **Fy = F·sinα** (α מהקורה).
- ב-ΣM: **רק Fy**.
- כוח אופקי → **רק הסמך הנייח** (או ריתום).
