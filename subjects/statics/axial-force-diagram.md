# 10. מהלך כוחות צירים (N)

> ⚡ **בקצרה:** מהלך N = גרף של **המתיחה או הלחיצה** לאורך הקורה. רק כוחות **אופקיים** (ו-**Fx** של כוחות באלכסון) משנים אותו.

---

## 🪢 הרעיון

- **משיכת חבל:** החבל **מתוח** → N **חיובי**.
- **עמוד** שמשהו כבד עומד עליו: **לחוץ** → N **שלילי**.
- בקורה שוכבת: רק מה ש**דוחף או מושך לאורך** הקורה.

## 📋 הכללים (משמאל לימין)

1. מתחילים ב-**0**.
2. כוח אופקי שמצביע **שמאלה** → N **עולה** (+).
3. כוח אופקי שמצביע **ימינה** → N **יורד** (−).
4. בין כוחות → קו **אופקי** (N קבוע).
5. כוחות **אנכיים** ומומנטים → **לא משנים** את N.
6. בקצה הימני → חוזרים ל-**0** ✅

> 💡 למה שמאלה = פלוס? כוח בצד שמאל שמושך **שמאלה** → **מותח** את הקורה.

## 🧩 דוגמה, צעד אחר צעד

הקורה מ**פתק 5**: 5 m, נייח ב-A, נייד ב-B. כבר מצאנו: **Fx = 8.66 kN** ימינה ב-3 m, ו-**Ax = 8.66 kN** שמאלה.

1. ב-A: Ax מצביע **שמאלה** → **N = +8.66** (מתיחה)
2. מ-0 עד 3 m: אין כוחות אופקיים → **קבוע, +8.66**
3. ב-3 m: Fx מצביע **ימינה** → 8.66 − 8.66 = **0**
4. מ-3 עד 5 m: **N = 0**
5. ב-B: סמך נייד, אין כוח אופקי → נשאר **0** ✅ (בדיקה)

```
 N (kN)
 +8.66 +-----------+
       |###########|
     0 +-----------+-------+--> x (m)
       0           3       5
```

> 💡 **רשות:** אם הנייח היה ב-**B** (והנייד ב-A), הקטע **3–5** היה **לחוץ** (−8.66), והקטע 0–3 היה ריק. **מי שמחזיק אופקית** קובע איזה חלק עובד.

## ⚠️ טעויות נפוצות

- להכניס כוחות **אנכיים** ל-N.
- לשכוח את **Ax** בתחילת הגרף.
- להשתמש ב-**F** כולו במקום ב-**Fx**.

## 🧠 לזכור

- **רק אופקי** (ו-Fx).
- משמאל לימין: שמאלה = **+**, ימינה = **−**.
- מתיחה **+**, לחיצה **−**.
