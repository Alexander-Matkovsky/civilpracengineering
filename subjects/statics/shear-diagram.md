# 9. מהלך כוחות גזירה (S)

> ⚡ **בקצרה:** מהלך S = גרף של **S לאורך כל הקורה**. הולכים **משמאל לימין** ו"עוקבים אחרי החיצים": חץ **למעלה** → קפיצה **למעלה**, חץ **למטה** → קפיצה **למטה**.

---

## 🚶 הרעיון

- כמו **מד גובה** בטיול: מתחילים ב-0, וכל חץ מזיז למעלה או למטה.
- בסוף הקורה חוזרים ל-**0**. אם לא → יש טעות.

## 📋 הכללים (משמאל לימין)

1. מתחילים ב-**0**.
2. **כוח מרוכז** למעלה → קפיצה **למעלה** בגודל הכוח. למטה → **למטה**.
3. בין כוחות, **בלי עומס** → קו **אופקי**.
4. **עומס מפורס** q למטה → קו **משופע למטה**. הירידה הכוללת = **q · L**.
5. **מומנט מרוכז** → **לא משנה** את S.
6. כוחות **אופקיים** (ו-Fx) → **לא משנים** את S.
7. בקצה הימני → חוזרים ל-**0** ✅

## 🧩 דוגמה: כוח מרוכז

הקורה מ**פתק 3**: 6 m, **Ay = 8**, **P = 12** ב-2 m, **By = 4**.

1. ב-A: Ay = 8 למעלה → **S = +8**
2. מ-0 עד 2 m: אין עומס → **אופקי, +8**
3. ב-2 m: P = 12 למטה → 8 − 12 = **−4**
4. מ-2 עד 6 m: אין עומס → **אופקי, −4**
5. ב-B: By = 4 למעלה → −4 + 4 = **0** ✅ (בדיקה)

```
 S (kN)
  +8 +-------+
     |#######|
   0 +-------+---------------+--> x (m)
             |###############|
  -4         +---------------+
     0       2               6
```

## 🧩 דוגמה קטנה: עומס מפורס

קורה 6 m, **q = 2 kN/m** על כולה. נייח ונייד בקצוות → **Ay = By = 6 kN**.

1. ב-A: Ay = 6 למעלה → **+6**
2. לאורך הקורה: S יורד **בקו ישר**, בסך הכול 2 · 6 = **12**
3. בסוף: 6 − 12 = **−6**, ואז By = 6 למעלה → **0** ✅
4. S = 0 **באמצע** (x = 3 m). זה חשוב לפתק 11.

```
 S (kN)
  +6 *
     |   *
     |       *
   0 +-----------*-----------+--> x (m)
                     *       |
                         *   |
  -6                         *
     0           3           6
```

## ⚠️ טעויות נפוצות

- לשכוח את **הקפיצות של התגובות**.
- מתחת לעומס מפורס לצייר קו **אופקי** במקום **משופע**.
- לא לבדוק שהגרף **חוזר ל-0** בסוף.

## 🧠 לזכור

- משמאל לימין, **עוקבים אחרי החיצים**.
- כוח = **קפיצה**, עומס מפורס = **שיפוע**, מומנט מרוכז = **כלום**.
- בסוף: **0**.
