# 7. קורה בריתום (קונזולה)

> ⚡ **בקצרה:** ריתום = **3 תגובות**: **Ax**, **Ay**, **M_A**. ΣFy → Ay. ΣM סביב הריתום → **M_A**.

---

## 🏠 הרעיון

- **מדף** שמוברג לקיר, **מרפסת**, **קרש קפיצה** בבריכה.
- סמך אחד בלבד, אבל הוא **חוסם הכול**: תזוזה **וגם** סיבוב (פתק 2).
- הקיר מונע מהקורה **להסתובב** → יש **מומנט תגובה M_A**.

## 📋 מתכון

1. **גוף חופשי:** בקיר לצייר **Ax**, **Ay** ו-**M_A** (לנחש כיוון, למשל ↻).
2. **ΣFy = 0** → **Ay** (פשוט סכום העומסים האנכיים).
3. **ΣFx = 0** → **Ax**.
4. **ΣM סביב A = 0** → **M_A**.
   - Ax ו-Ay עוברים דרך A → **0**.
   - **M_A נכנס לסכום**, עם הסימן שניחשנו, **בלי מרחק** (כמו בפתק 6).
5. **בדיקה:** ΣM סביב **הקצה החופשי** = 0?

## 🧩 דוגמה, צעד אחר צעד

קורה **4 m**, ריתום ב-A (שמאל). כוח **P = 5 kN** למטה, ב**קצה החופשי** C.

```
  //|                  P = 5 kN
  //|                    |
  //|                    v
  //|====================C
  //|
   A|<------- 4 m ------>|
```

1. **גוף חופשי:** Ax, Ay, M_A (ניחוש: ↻ = פלוס).
2. **ΣFy = 0:** Ay − 5 = 0 → **Ay = 5 kN** ✅ (למעלה)
3. **ΣFx = 0:** אין כוחות אופקיים → **Ax = 0** ✅
4. **ΣM סביב A = 0:**
   - P למטה, **מימין** ל-A → ↻ → **+5 · 4 = +20**
   - M_A (ניחוש ↻) → **+M_A**
   - 20 + M_A = 0 → **M_A = −20 kN·m** → בפועל **↺, 20 kN·m** ✅
5. **בדיקה, ΣM סביב C:**
   - Ay למעלה, **משמאל** ל-C → ↻ → **+5 · 4 = +20**
   - M_A → **−20**
   - P עובר דרך C → **0**
   - 20 − 20 = **0** ✅

> 💡 P רוצה לסובב את הקורה ↻ (הקצה יורד). הקיר מחזיק ↺. הגיוני.

## ↔️ ריתום בצד ימין?

- אותו מתכון.
- רק שהעומסים עכשיו **משמאל** ל-A → הסימנים מתהפכים (הטריק מפתק 1).

## ⚠️ טעויות נפוצות

- לשכוח את **M_A** ב-ΣM.
- **לכפול** את M_A במרחק.
- ריתום בצד **ימין**: לשכוח שהסימנים מתהפכים.

## 🧠 לזכור

- ריתום = **3** תגובות: Ax, Ay, **M_A**.
- ΣM סביב הריתום → **M_A** (בלי מרחק).
- יצא מינוס? → הכיוון **הפוך** מהניחוש.
