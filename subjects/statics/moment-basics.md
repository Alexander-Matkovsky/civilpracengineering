# 1. יסודות המומנט

> ⚡ **בקצרה:** מומנט = כמה חזק כוח **מסובב** משהו. **M = F · d**. עם כיוון השעון = **פלוס**.

---

## 🚪 הרעיון

- לדחוף דלת **ליד הציר** = קשה.
- לדחוף דלת **ליד הידית** = קל.
- אותו כוח, מרחק אחר → סיבוב אחר. **זה מומנט.**

## 🧮 הנוסחה

**M = F · d**

- **F** = הכוח [N]
- **d** = הזרוע: המרחק מהנקודה אל הכוח, **בניצב** (90°) לכוח [m]
- יחידות: **N·m** (או kN·m)

```
                    F
                    |
                    v
  O=================+
  |<------ d ------>|
```

**דוגמה:** כוח **10 N** למטה, **2 m** מימין ל-O → מסובב ↻ → **M = +20 N·m**

## 🔄 הסימן (המוסכמה בקורס)

- עם כיוון השעון ↻ = **+**
- נגד כיוון השעון ↺ = **−**

> ⚠️ בהרבה ספרים זה **הפוך**. בקורס ובבחינה: עם כיוון השעון = **פלוס**. תמיד.

## 👆 טריק: לאן זה מסובב?

1. לשים **אצבע** על הנקודה (היא לא זזה).
2. לדמיין שהכוח **דוחף**.
3. לאן זה מסתובב? ↻ = **+**, ↺ = **−**

קיצור לקורה שוכבת:

- כוח **למטה**, **מימין** לנקודה → ↻ **+**
- כוח **למטה**, **משמאל** לנקודה → ↺ **−**
- כוח **למעלה**, **מימין** לנקודה → ↺ **−**
- כוח **למעלה**, **משמאל** לנקודה → ↻ **+**

## 0️⃣ מתי המומנט הוא אפס?

- כשהכוח **עובר דרך הנקודה** → d = 0 → **M = 0**
- זה הטריק הכי חשוב לפתרון תרגילים (בפתק 3).

## ↗️ כוח באלכסון

הכוח לא ניצב לקורה? אז:

1. לפרק לרכיבים: **Fx** (אופקי) ו-**Fy** (אנכי).
2. לחשב מומנט **לכל רכיב** לבד.
3. לחבר, **עם הסימנים**.

**דוגמה:** מוט אופקי, **2 m**. ציר O בקצה השמאלי. בקצה הימני: כוח **10 N**, ב-**30°** למעלה-ימינה.

1. Fx = 10 · cos30° ≈ **8.66 N** → עובר דרך O → **מומנט 0**
2. Fy = 10 · sin30° = **5 N** למעלה, מימין ל-O → ↺ → **מינוס**
3. M_O = −5 · 2 = **−10 N·m**

## 🔁 זוג כוחות (רשות, טוב לדעת)

- **שני** כוחות: שווים בגודל, **הפוכים** בכיוון, **מקבילים**, במרחק d.
- סכום הכוחות = 0 → הגוף **לא זז**, רק **מסתובב**.
- **M = F · d**, ו**אותו מומנט סביב כל נקודה**.
- דוגמה: לסובב **הגה** בשתי ידיים.

## 🧠 לזכור

- **M = F · d**, כשהמרחק **ניצב** לכוח.
- ↻ = **+**, ↺ = **−** (בקורס).
- כוח שעובר דרך הנקודה → **0**.
