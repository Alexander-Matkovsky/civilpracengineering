# 2. סמכים ותגובות

> ⚡ **בקצרה:** סמך = מה שמחזיק את הגוף. כל כיוון שהסמך **חוסם** → יש **כוח תגובה** בכיוון הזה.

---

## 💡 הכלל היחיד שצריך

- הסמך **מונע תזוזה** בכיוון מסוים → יש **כוח תגובה** בכיוון הזה.
- הסמך **מונע סיבוב** → יש **מומנט תגובה**.

## 1️⃣ סמך נייח (ציר / פרק)

```
  ======O======
       / \
      /   \
     /_____\
    /////////
```

- **חוסם:** ימינה-שמאלה **וגם** למעלה-למטה.
- **מאפשר:** סיבוב.
- **תגובות: 2** → **Ax** (אופקי) + **Ay** (אנכי).

## 2️⃣ סמך נייד (גלגלת)

```
  ======O======
       / \
      /   \
     /_____\
      o   o
    /////////
```

- **חוסם:** רק תזוזה **ניצבת** למשטח.
- **מאפשר:** החלקה לאורך המשטח + סיבוב.
- **תגובות: 1** → כוח **ניצב למשטח** (על רצפה = אנכי).

## 3️⃣ ריתום (נלמד בקצרה)

```
  //|
  //|==========
  //|
```

- **חוסם:** הכול. תזוזה **וגם** סיבוב.
- **תגובות: 3** → **Ax** + **Ay** + **מומנט M_A**.

## 🧠 לזכור: כמה תגובות?

- נייח → **2**
- נייד → **1**
- ריתום → **3**

## ✏️ דיאגרמת גוף חופשי

לפני **כל** תרגיל:

1. לצייר את הגוף **לבד**, בלי הסמכים.
2. לצייר את כל **העומסים** (הכוחות החיצוניים).
3. להחליף כל סמך **בתגובות שלו** (חיצים).
4. לרשום את **המרחקים**.

> 💡 לא ידוע לאן התגובה מצביעה? **לנחש** כיוון. יצאה תוצאה **שלילית**? → הכיוון האמיתי **הפוך**. זה הכול.
