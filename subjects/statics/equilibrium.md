# 3. שיווי משקל: למצוא את התגובות

> ⚡ **בקצרה:** גוף שעומד במקום → **הכול מתאפס**. 3 משוואות → מוצאים את התגובות בסמכים.

---

## ⚖️ 3 המשוואות

1. **ΣFx = 0** → כל הכוחות האופקיים
2. **ΣFy = 0** → כל הכוחות האנכיים
3. **ΣM = 0** → כל המומנטים, סביב **איזו נקודה שרוצים**

## 🔢 למה דווקא נייח + נייד?

- 3 משוואות → אפשר למצוא עד **3 נעלמים**.
- נייח (**2**) + נייד (**1**) = **3** ✅
- בדיוק מספיק.

## 🎯 טריק הזהב

**לחשב ΣM סביב סמך.**

- התגובות של הסמך הזה **עוברות דרך הנקודה** → מומנט **0** → נעלמות.
- נשאר **נעלם אחד**. קל.

## 🧩 דוגמה מלאה, צעד אחר צעד

קורה באורך **6 m**. סמך **נייח** ב-A (שמאל). סמך **נייד** ב-B (ימין). כוח **P = 12 kN** למטה, **2 m** מ-A.

```
          P = 12 kN
              |
              v
  A===========+=======================B
  ^                                   ^
                                      o
  |<-- 2 m -->|<-------- 4 m -------->|
```

`^` = סמך נייח · `^` + `o` = סמך נייד

**שלב 1: גוף חופשי**

- ב-A: **Ax** + **Ay** (נייח = 2)
- ב-B: **By** למעלה (נייד = 1)
- 3 נעלמים, 3 משוואות ✅

**שלב 2: ΣM סביב A = 0** (טריק הזהב: Ax ו-Ay נעלמים)

- P: למטה, **מימין** ל-A → ↻ → **+12 · 2 = +24**
- By: למעלה, **מימין** ל-A → ↺ → **−By · 6**
- 24 − 6·By = 0 → **By = 4 kN** ✅

**שלב 3: ΣFy = 0** (למעלה = פלוס)

- Ay + By − 12 = 0
- Ay + 4 − 12 = 0 → **Ay = 8 kN** ✅

**שלב 4: ΣFx = 0**

- אין כוחות אופקיים → **Ax = 0** ✅

**שלב 5: בדיקה, ΣM סביב B = 0**

- Ay: למעלה, **משמאל** ל-B → ↻ → **+8 · 6 = +48**
- P: למטה, **משמאל** ל-B → ↺ → **−12 · 4 = −48**
- 48 − 48 = **0** ✅ נכון!

> 💡 הכוח קרוב יותר ל-A → **A סוחב יותר** (8 מתוך 12). הגיוני.

## 📋 מתכון לכל תרגיל

1. **גוף חופשי** (פתק 2).
2. **ΣM סביב סמך** → נעלם אחד.
3. **ΣFy = 0** → עוד נעלם.
4. **ΣFx = 0** → האחרון.
5. **בדיקה:** ΣM סביב נקודה **אחרת** = 0?

## ⚠️ טעויות נפוצות

- מרחק **לא ניצב** לכוח.
- **סימן** שגוי או שנשכח (+/−).
- **יחידות** מעורבבות (kN עם N, cm עם m).
- תגובה של סמך **שנשכחה**.
- תגובה של סמך נייד **לא ניצבת** למשטח.
