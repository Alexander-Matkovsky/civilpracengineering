# 11. מהלך מומנטים (M)

> ⚡ **בקצרה:** מהלך M = גרף **מומנט הכפיפה** לאורך הקורה. **השינוי ב-M = השטח של מהלך S**. ה-M הכי גדול נמצא איפה ש-**S = 0**.

---

## 🧗 הרעיון

- S אומר **כמה מהר** M משתנה. כמו **שיפוע** של שביל.
- S חיובי → M **עולה**. S שלילי → M **יורד**. S = 0 → **פסגה**.

## 📋 הכללים (משמאל לימין)

1. בקצה **חופשי**, או בסמך נייח/נייד **בקצה** → **M = 0** (אם אין שם מומנט מרוכז).
   - בריתום: **לא** 0. ריתום משמאל → M מתחיל ב**ערך של M_A** (עם הסימן).
2. **השינוי ב-M** בין שתי נקודות = **השטח** של מהלך S ביניהן (מעל הציר +, מתחת −).
3. S **אופקי** (בלי עומס) → M **קו ישר**.
4. S **משופע** (עומס מפורס) → M **קשת** (פרבולה).
5. S **חוצה 0** → M **מקסימלי** (או מינימלי) שם.
6. **מומנט מרוכז** → **קפיצה** ב-M: ↻ = קפיצה **למעלה**, ↺ = **למטה**.
7. בקצה הימני (חופשי או סמך) → חוזרים ל-**0** ✅

## 🧩 דוגמה: כוח מרוכז

הקורה מ**פתק 3**. מהלך S מ**פתק 9**: **+8** מ-0 עד 2 m, **−4** מ-2 עד 6 m.

1. ב-A (נייח בקצה): **M = 0**
2. מ-0 עד 2: שטח S = 8 · 2 = **+16** → **M(2) = +16 kN·m**
3. מ-2 עד 6: שטח S = −4 · 4 = **−16** → M(6) = 16 − 16 = **0** ✅ (B בקצה → 0, בדיקה)
4. צורה: **קווים ישרים**. הפסגה ב-x = 2, בדיוק איפה ש-S **מחליף סימן** ✅

```
 M (kN*m)
 +16         *
 +12             *
  +8     *           *
  +4                     *
   0 *-----------------------*--> x (m)
     0       2               6
```

## 🧩 דוגמה קטנה: עומס מפורס

הקורה מהדוגמה הקטנה בפתק 9: 6 m, q = 2 kN/m. S יורד מ-+6 ל-−6, ו-**S = 0 ב-x = 3**.

1. M(0) = **0**
2. M(3) = שטח המשולש של S מ-0 עד 3 = ½ · 3 · 6 = **+9 kN·m** (המקסימום)
3. M(6) = 9 − 9 = **0** ✅
4. צורה: **קשת** (פרבולה)

```
 M (kN*m)
  +9             *
  +8         *       *
  +5     *               *
   0 *-----------------------*--> x (m)
     0           3           6
```

> ⚠️ כאן M חיובי מצויר **למעלה**. יש מרצים שמציירים אותו **למטה** (בצד המתוח של הקורה). **לבדוק במחברת.**

## ⚠️ טעויות נפוצות

- לשכוח שבקצה חופשי או בסמך בקצה **M = 0**.
- מתחת לעומס מפורס לצייר **קו ישר** במקום **קשת**.
- לשכוח את **הקפיצה** של מומנט מרוכז.
- לחפש את המקסימום במקום הלא נכון (הוא איפה ש-**S = 0**).

## 🧠 לזכור

- שינוי ב-M = **שטח S**.
- S = 0 → **M מקסימלי**.
- מומנט מרוכז → **קפיצה** ב-M (וב-S כלום).
