# 4. עומס מפורס

> ⚡ **בקצרה:** עומס מפורס = עומס **מרוח** לאורך הקורה. לחישוב תגובות: להחליף אותו **בכוח אחד**, **Q = q · L**, ב**אמצע** הקטע.

---

## 📚 הרעיון

- תיק כבד **בנקודה אחת** על מדף = עומס **מרוכז** (כמו בפתק 3).
- שורת ספרים **לאורך** המדף = עומס **מפורס**.
- בשרטוט: מלבן עם **הרבה חיצים קטנים**.

## 📏 מה זה q

- **q** = כמה כוח יש על **כל מטר** [kN/m]
- בעבודה כתוב **t/m** (טון למטר). אותו רעיון.
- דוגמה: q = 3 kN/m → כל מטר של קורה נושא **3 kN**.

## 🔁 להחליף בכוח אחד

1. **Q = q · L**, כש-L = אורך **הקטע שעליו העומס** (לא כל הקורה!).
2. Q פועל ב**אמצע** הקטע.
3. מכאן: Q הוא **כוח רגיל**. נכנס ל-ΣFy ול-ΣM כמו בפתק 3.

```
  before:
   q = 3 kN/m
   |  |  |  |  |
   v  v  v  v  v
  A=============+=============B
  |<--- 4 m --->|

  after:
       Q = 12 kN
          |
          v
  A=======+=====+=============B
  |<-2 m->|
```

> 💡 עומס עם חיצים **למעלה**? אותו דבר, רק Q מצביע **למעלה**.

## 🧩 דוגמה, צעד אחר צעד

קורה **8 m**. נייח ב-A (שמאל), נייד ב-B (ימין). עומס **q = 3 kN/m** על **4 m** השמאליים.

```
   q = 3 kN/m
  |   |   |   |   |
  v   v   v   v   v
  A================+================B
  ^                                 ^
                                    o
  |<----- 4 m ---->|<----- 4 m ---->|
```

1. **Q** = 3 · 4 = **12 kN**, ב-**2 m** מ-A (אמצע הקטע).
2. **ΣM סביב A = 0:**
   - Q למטה, **מימין** ל-A → ↻ → **+12 · 2 = +24**
   - By למעלה, **מימין** ל-A → ↺ → **−By · 8**
   - 24 − 8·By = 0 → **By = 3 kN** ✅
3. **ΣFy = 0:** Ay + 3 − 12 = 0 → **Ay = 9 kN** ✅
4. **ΣFx = 0:** אין כוחות אופקיים → **Ax = 0** ✅
5. **בדיקה, ΣM סביב B:**
   - Ay למעלה, **משמאל** ל-B → ↻ → **+9 · 8 = +72**
   - Q למטה, **משמאל** ל-B, במרחק **6 m** → ↺ → **−12 · 6 = −72**
   - 72 − 72 = **0** ✅

> 💡 כל העומס בצד של A → **A סוחב יותר** (9 מתוך 12). הגיוני.

## ⚠️ טעויות נפוצות

- L = כל הקורה, במקום **רק הקטע** עם העומס.
- Q לא ב**אמצע** הקטע.
- מרחק של Q: מהנקודה שסביבה מחשבים **עד אמצע הקטע**, לא עד קצה העומס.
- ⚠️ Q הוא כלי **לחישוב**. בשרטוט מהלכים (פתקים 9, 11) העומס **נשאר מפוזר**.

## 🧠 לזכור

- **Q = q · L** (L = רק הקטע עם העומס).
- Q ב**אמצע** הקטע.
- אחרי ההחלפה: **כוח רגיל**.
