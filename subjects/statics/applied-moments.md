# 6. מומנט מרוכז על קורה

> ⚡ **בקצרה:** מומנט מרוכז = **סיבוב** שמפעילים על הקורה (חץ מעוגל). נכנס **רק ל-ΣM**, **בלי לכפול במרחק**, ו**אותו ערך סביב כל נקודה**.

---

## 🔧 הרעיון

- לסובב **מפתח ברגים** או **מברג**: לא דוחפים לשום כיוון, רק **מסובבים**.
- זה בעצם **זוג כוחות** (פתק 1): שני כוחות הפוכים → סכום **0**, נשאר רק **סיבוב**.

## 👀 איך מזהים

- בשרטוט: **חץ מעוגל** ↻ או ↺ ליד הקורה.
- יחידות של **מומנט**: kN·m. בעבודה: **tm** (טון·מטר).
- 💡 כתוב **tm** (ולא t)? → זה **מומנט**, לא כוח.

## 📋 3 כללים

1. **ΣFx, ΣFy:** לא נכנס. (אין כוח.)
2. **ΣM:** נכנס **כמו שהוא**. **לא** כופלים במרחק.
3. **סימן:** לפי כיוון החץ. ↻ = **+**, ↺ = **−** (המוסכמה בקורס).

> 💡 **איפה** המומנט יושב על הקורה? לתגובות **לא משנה**. למהלך M (פתק 11) **כן** משנה.

## 🧩 דוגמה, צעד אחר צעד

קורה **4 m**. נייח ב-A, נייד ב-B. העומס היחיד: מומנט **M0 = 8 kN·m**, **עם כיוון השעון**, ב-**1 m** מ-A.

```
       M0 = 8 kN*m (CW)
          @
  A=======+=====================B
  ^                             ^
                                o
  |<-1 m->|<-------- 3 m ------>|
```

`CW` = עם כיוון השעון ↻

1. **ΣM סביב A = 0:**
   - M0 ↻ → **+8** (בלי מרחק!)
   - By למעלה, **מימין** ל-A → ↺ → **−By · 4**
   - 8 − 4·By = 0 → **By = 2 kN** ✅ (למעלה)
2. **ΣFy = 0:** Ay + 2 = 0 → **Ay = −2 kN** → בפועל **למטה** ✅
3. **ΣFx = 0:** אין כוחות אופקיים → **Ax = 0** ✅
4. **בדיקה, ΣM סביב B:**
   - Ay = 2 kN **למטה**, **משמאל** ל-B → ↺ → **−2 · 4 = −8**
   - M0 ↻ → **+8**
   - −8 + 8 = **0** ✅

> 💡 התגובות יוצאות **זוג כוחות הפוך** (2 למעלה, 2 למטה) שמבטל את הסיבוב. הגיוני.

## ⚠️ טעויות נפוצות

- **לכפול** את M0 במרחק.
- להכניס את M0 ל-**ΣFy**.
- **סימן** הפוך: לבדוק את כיוון החץ.
- לבלבל **t** (כוח) עם **tm** (מומנט).

## 🧠 לזכור

- מומנט מרוכז → **רק ΣM**.
- **בלי מרחק**, אותו ערך סביב **כל נקודה**.
- ↻ = **+**, ↺ = **−**.
