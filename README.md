# Study Notebook

My notes, one place, plain Markdown.

📅 **[הקורסים שלי: סמסטר א](courses.md)**: מרצים, שעות, קבצים באתר ודדליינים.

## Layout

```
README.md          ← you are here: overview and subject index
courses.md         ← this semester's courses, lecturers, schedule, deadlines
inbox.md           ← quick captures to sort later
subjects/          ← one folder per subject, one file per topic
templates/note.md  ← starting point for a new note
```

## Working with Claude

Things to ask for:

- "Make notes on chapter 3 of <book>" (paste text, a PDF or a photo of your notes)
- "Explain <concept> and add it to my <subject> notes"
- "Quiz me on <topic>" (uses the review questions in each note)
- "Sort my inbox"
- "Summarize everything I have on <subject> before the exam"
